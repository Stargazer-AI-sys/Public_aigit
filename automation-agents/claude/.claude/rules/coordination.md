# 파일 책임과 인계

- 작업 시작 시 마스터가 지정한 작업 ID·역할·수정 허용 파일·입력 버전·완료 조건을 확인한다. 누락된 권한을 추측하지 않는다.
- 프로젝트 원본은 현재 작업 폴더에서 상대경로로 다룬다. 이 운영 폴더로 소스·작업기록·산출물을 복제하지 않는다.
- 읽기 전용 검토 중 결함을 발견하면 수정하지 않고 위치·재현·영향을 반환한다.
- 다른 담당이 같은 파일을 수정 중이면 마스터가 순서를 조정할 때까지 해당 파일의 변경을 보류한다. 이 규칙은 실제 파일 잠금 구현을 뜻하지 않는다.
- 반환에는 변경 파일·실제 시험·증거·미검증·다음 담당을 포함한다. 종료 코드 미수집이나 사용자 보고를 직접 검증으로 바꾸지 않는다.
- 역할 분리는 별도 에이전트 생성 권한이 아니다. 마스터의 명시 작업 배분 범위를 따른다.
