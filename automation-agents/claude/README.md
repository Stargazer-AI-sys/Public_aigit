# 자동화용 Claude 운영 자료

> 버전 0.1 | 2026-10-27

이 폴더는 프로젝트 관리 자동화에 참여하는 Claude의 전용 지침·스킬 원본이다. 기존 ../../Claudecode 문서에서 복사·가져오기 하지 않고 새로 작성했다. 기존 폴더와 별도로 관리한다.

- [역할 지침](CLAUDE.md)
- [작업 분담 규칙](.claude/rules/coordination.md)
- [인계 스킬](.claude/skills/automation-handoff/SKILL.md)
- [실행 설정](.claude/settings.json)
- [연결 시작기](../../gptgit/project-management/tools/start_claude.ps1)

작업 위치는 ../../gptgit/project-management를 유지한다. 소스·명세·실행 기록·검증·산출물은 해당 프로젝트 원본에만 저장한다. 이 폴더에는 프로젝트 상태 사본이나 인증정보를 넣지 않는다.

시작기는 --add-dir와 세션 환경변수로 이 폴더의 지침·스킬을 연결하고 --settings로 설정을 적용한다. 추가 디렉터리만 지정하면 설정 파일까지 자동 적용되는 것은 아니다. 사용자 설정은 이 실행에서 제외하며, 인증은 기존 Claude Pro 로그인을 재사용한다. 관리자 정책은 별도로 적용될 수 있다.

스킬을 추가할 때 이곳에 원본을 저장하고 메타데이터·참조·실제 발견 여부를 검증한다. 개인 ~/.claude/skills로 자동 복사하지 않는다. 같은 이름의 개인·내장 스킬과 충돌하면 자동으로 덮어쓰지 않고 실제 선택된 스킬을 확인한다.

현재 보류: 가이드 정식 제작과 기존 HTML·가이드 실행계획·simple-user-guide 원문의 Claude 전송. 새 운영 폴더 연결 요청은 그 보류를 해제하지 않는다.

폴더 분리는 관리 구조다. 운영체제 보안 격리나 모든 셸 접근 차단을 뜻하지 않는다. 최초 대화형 실행의 /context, /memory, /skills에서 로딩을 확인해야 실제 적용 완료로 판정한다.
