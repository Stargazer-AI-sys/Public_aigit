## 3. 사용자 결정 지점
- A·B 모두 **실행할 때마다 사용자가 직접 누르거나 명령을 실행**해야 한다. `Project_Refactor/CLAUDE.md:19,26`에도 "유료 API 실행 전 사용자에게 알린다"고 적혀 있다. 비용이 매우 작으므로 이 확인은 지금 수준으로 충분하다.
- 제안(선택): A에는 B 같은 횟수·금액 한도가 없다. 실수로 많은 파일을 `gpt-6.1-sol`로 돌리는 경우만 대비하면 된다. 현재 금액 규모로는 급하지 않다.
- 가장 확실한 안전장치: OpenAI 결제 화면에서 **월 사용 한도(usage limit)**를 정해 두면 코드와 상관없이 그 이상 청구되지 않는다. (확인 필요: OpenAI 계정 설정은 이 PC에서 볼 수 없다)
