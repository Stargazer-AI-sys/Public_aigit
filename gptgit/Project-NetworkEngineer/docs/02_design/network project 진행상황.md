## $1 프로젝트 개요

## $2 전체 아키텍처

[전체 설계 `$1`](전체%20설계%20및%20구축%20단계.md#architecture)이 목표 Hybrid·On-Premise 구조의 원본이다. 과거 반복된 Hybrid 도식은 한 곳으로 통합했다.

## $3 현재 환경

[실습 환경 및 주소](실습%20환경%20및%20주소.md)가 VMware/PNETLab, Linux, 장비 Image, 포트·IP·경로·NAT의 원본이다. 다음 작업에 관련된 절만 확인한다.

## $4 현재 설계

[전체 설계 `$2`·`$3`](전체%20설계%20및%20구축%20단계.md#address-plan)에서 VLAN 역할 방향·통신 기준을 관리한다. 현재 구현과 목표 구조를 구분하며 전체 호스트 IP·정책이 확정됐다고 간주하지 않는다.

## $7 미확정 사항·보류

### %1 다음 설계에 필요한 결정

- 개발/테스트 VLAN10·운영 VLAN20은 사용자 제안과 적합성 검토까지 진행했다. 최종 호스트 배치·대역 채택·확장 범위는 구체화 필요.
- 운영 L2 두 대의 실제 배치·연결, WEB-01/WEB-02/DB-01·별도 Test DB의 역할·현재 구성은 미확정.
- 전체 호스트 수·주소, 실습 VLAN DHCP·고정/예약 정책, 개발→운영 허용 흐름·ACL은 미설계. 관리망의 기존 DHCP와 구분한다.

### %2 후속 Phase에서 결정

Firewall 제품·방식, 동적 Routing Protocol, AWS Region/VPN 방식, DB Replication, Load Balancer 상세, Monitoring 위치, 실제 HA 범위, Security 세부 정책, Git/CI-CD/배포 서버 등 배포 방식. 그 단계에 필요한 때 확인하며 지금의 필수 입력으로 확대하지 않는다.

### %3 보류·비차단 미확인

- [보류] 학교 자동 OFF / VBS / Nested Virtualization. 해당 환경의 명시적 재개 요청이 있을 때 조사한다. 집 성공을 학교 해결로 기록하지 않는다.
- [비차단 미확인] CORE·EDGE Template 선택값, .128의 과거 수동 입력에서 현재 DHCP로 이어진 변경 경위. 현재 기본 통신을 막는 조건으로 두지 않는다.
- 전체 VM 무충돌·미검증 추가 기능은 완료 주장 범위 밖이다. 별도 필요가 있을 때만 범위를 정해 확인한다.
