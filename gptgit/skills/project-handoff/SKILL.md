# 프로젝트 인계 점검

> 스킬 버전: 0.4 | 최종 수정: 2026-10-28

대상 프로젝트 루트와 재개하려는 작업을 기준으로 최신 상태를 복원해 채팅으로 보고한다.

- 스킬 보관 위치와 작업 대상을 구분한다. 대상 프로젝트의 최신 README·규칙에서 공식 작업기록·현재 상태 문서를 찾고, 이 관리 프로젝트의 기록을 다른 프로젝트의 상세 상태 기준으로 사용하지 않는다.

- 루트가 주어지면 README에서 진입점을 찾고 AGENTS·해당 상세 규칙·최신 작업기록을 확인한다. 여러 프로젝트 중 대상이 불명확할 때만 대상을 묻는다. 전체 저장소를 먼저 읽지 않는다.
- 문서가 가리키는 최신 소스·스키마·검증 자료 중 해당 작업에 필요한 부분만 대조한다. 과거 ZIP·사본·외부 PC 경로를 현재 실행 원본으로 자동 선택하지 않는다.
- PC 이동 시 실제 작업 폴더를 기준으로 경로를 해석하고, 기록의 PC별 설치·검증 결과는 당시 환경의 정보로 구분한다. 이번 작업에 필요한 스킬·자원만 확인한다. 개인 설치본과 프로젝트 지정 공유 원본이 다르거나 설치본이 없으면 차이를 알리고 공유 원본을 읽어 적용한다. 설치·등록을 주장하거나 별도 요청 없이 설치본을 덮어쓰지 않는다.
- 현재 상태를 기록상 완료, 직접 확인, 사용자 보고, 제안·미확정, 미검증으로 구분한다. 과거 안내와 최신 인계가 다르면 시점·적용 범위·증거를 확인하고 해결하지 못한 충돌을 표시한다.
- 파일 존재는 구현·동작 검증의 증거가 아니다. 로컬 문서만 보고 GitHub 동기화·API 잔액·스킬 등록·사용자 장비의 동작을 확정하지 않는다. 사용자 확인과 AI 실측을 구분한다.
- 누락 자료가 있으면 가능한 점검을 계속하고 그 자료에 의존하는 판단만 보류한다. 미완료 문구가 과거 이력인지 최신 할 일인지 문맥을 확인한다.
- 사용자의 최신 설명을 함께 반영한다. pull 완료 보고와 과거 원격 반영 미확인 기록을 구분하고, 과거 문구만으로 같은 질문·동기화를 반복하지 않는다. 과거 검사를 일괄 반복하지 않고 현재 작업과 환경 차이에 필요한 검증만 수행한다.
- 결과는 기준 경로·소스, 근거를 붙인 현재 상태, 충돌·미확인, 우선순위와 의존성을 반영한 다음 행동·담당으로 간결하게 정리한다. 이미 보류된 작업을 임의로 재개하거나 완료율·일정을 만들지 않는다.
- 기본은 읽기 전용이다. 점검 요청만으로 파일·작업기록·스키마를 수정하거나 코드를 실행·설치하지 않는다. Git 동기화·유료 API·외부 게시도 별도 허용 범위에서만 수행한다. 별도 에이전트는 사용자의 요청 또는 적용 지침이 허용할 때만 사용한다.
- 실행까지 요청받은 재개라면 다음 작업의 대상·범위와 필요한 사용자 실행 요청이 확인된 부분은 계속한다. 기록의 제안·할 일을 허가로 확대하지 않는다. 필수 입력·주요 결정·추가 권한이 필요한 부분만 질문하고, 답변에 의존하지 않는 확인은 계속한다. 명확한 재개 요청이 없는 보류 작업은 유지한다.
- 인계 기록 갱신을 요청받으면 다음 작업의 대상·목적·첫 행동·완료 기준·담당·필요 입력과 보류 작업의 재개 조건을 대상 프로젝트의 기존 기록·형식에 맞춰 남긴다. 스킬을 개인 설치하거나 다른 프로젝트에서 사용할 때 보관 원본의 상대경로·관리 전용 워크플로에 의존하지 않는다.

## 선별 복원과 다음 행동

- 제목·최신 인계로 중단 지점을 찾고, 해당 행동의 기존 역할·설계·결정 원본에서 필요한 절만 대조한다. 전체 작업기록을 한 번에 불러오지 않는다. 읽은 범위가 잘렸다면 미확인 구간을 보존한다.
- 기록과 아직 저장되지 않은 현재 대화를 대조해 결정 완료·구현 필요·검증 필요·실제 미정을 구분한다. 미구현을 미정으로 확대하여 이미 확정된 역할이나 방향을 다시 질문하지 않는다.
- 새 담당 세션에는 명세 Task ID·목표·완료 조건·확정 결정·관련 원본 절/버전·쓰기 범위·보류·현재 근거를 전달한다. 전체 부모 대화 복사는 기본으로 하지 않는다. 계획된 세션 분담은 해당 프로젝트의 승인 범위 안에서 적용한다.
- 인계 기록 갱신이 승인된 실행에서 예상외 작업량 확대가 생기면 짧게 알린 뒤 완료·미해결·근거·다음 행동을 기존 원본에 남겨 인계한다. 문서 읽음과 판단 근거 확보를 구분한다.
