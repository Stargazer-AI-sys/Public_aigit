# 위키 편집

적용 버전 0.1 · 적용일 2026-11-06. 이 스킬은 2026-11-05 기준 위키 편집 스킬 원본 버전 0.1을 이 프로젝트에 맞게 이식한 독립 사본이다.

이 프로젝트의 README·AGENTS와 작업 승인 범위를 먼저 확인한다. 내용 분류는 [위키 기준](../../wiki/AGENTS.md), 메타데이터는 [스키마](references/schema.md)를 각각 단일 기준으로 따른다. 실행별 원문·증거는 해당 docs/workflows 실행 기록의 보관 원본이며 위키 설명과 구분한다. 기존 docs를 raw로 이동하거나 자동 복제하지 않는다.

1. 관련 원문과 기존 페이지의 주제·중복을 확인하고 기존 내용을 우선 갱신한다. 원문 시점·조건·예외·상충·보류·미검증을 보존한다.
2. 자료 목록을 반복하지 말고 근거를 주장 가까이에 연결해 설명한다. 사실·사용자 보고·추정·제안을 구분하고 근거가 부족하면 미확인으로 둔다.
3. 상위 공통 원본은 실제 필요한 절을 검토하되 지식 문서에는 스키마의 상위 원본 참조 경계에 따라 프로젝트 AGENTS 진입점과 원본 이름·버전·절을 기록한다. 스키마와 필요한 [틀](assets/templates/)을 적용한다. 구조 페이지의 Mermaid와 설명은 실제 확인과 목표를 구분한다.
4. 승인 범위의 변경 페이지를 프로젝트 루트에서 지정해 검사한다. 이 프로젝트 전용 또는 시스템 공용 Python과 PyYAML이 준비된 경우 예시는 다음과 같다.

   ```powershell
   .local/wiki-editor-venv/Scripts/python.exe skills/wiki-editor/scripts/check_wiki.py wiki/경로/문서.md
   ```

환경 준비와 다른 PC의 확인은 [실행 환경](../../docs/runtime.md)을 따른다.

검사기는 읽기 전용이며 형식·대상 경로 검사 통과는 원문 정확성·최신성·도식 렌더링·내용 검증을 뜻하지 않는다. 필요한 수동 대조와 미확인 사항을 보고한다. Python 또는 PyYAML이 없으면 설치·환경 변경을 임의로 수행하지 않고 검사 불가를 보고한다. 설치·앱 등록·외부 작업·Git 권한을 이 스킬로 확대하지 않는다.
