# 위키 편집

버전 0.4 · 2026-11-18. 이 파일은 위키 작성 기준의 원본이다.

관련 입력과 수정할 기존 문서만 읽는다. 한 앱·주제는 분류별 한 문서가 기본이며 Task마다 페이지를 만들지 않는다. 내용이 없는 분류는 만들지 않는다.

| 폴더 | 담을 내용 |
| --- | --- |
| architecture | 구조·연결 |
| decisions | 선택과 이유 |
| features | 기능·조건 |
| index | 문서로 직접 가는 링크 |
| log | 중요한 결과·변경 요약 |
| operations | 실행·운영·문제 해결 |

YAML은 필요한 문서에만 아래처럼 짧게 쓴다. 색인·지침에는 불필요하다.

```yaml
---
updated: 2026-11-18
status: current
sources: [../../tools/dispatch_task.py]
---
```

근거·조건·미검증은 본문에 보존하고 사실과 제안을 구분한다. 원문·리뷰·로그를 복제하지 않는다. 색인에서 본문으로 바로 연결하며 중간 색인·상호 지침 순회를 만들지 않는다. 작성 후 변경한 내용과 링크만 확인한다. 별도 스키마·형식 검사·분량 맞추기·전체 문서 검사는 필수가 아니다.
