# 담당 실행

버전 0.4 · 2026-11-18

명시 모델·실제 확인·새 담당 탭은 [공유 위임 기준](../../../skills/delegation-reporting/SKILL.md)을 따른다. 실제 시작에는 [실행 환경](../../docs/runtime.md)의 도구를 사용한다. 이미 확인한 기준을 다시 읽지 않는다.

Astra는 마스터, Codex 담당은 Luna·Terra, Claude는 기획 검토·개발이다. QA·기획 검토는 원본 read-only다. 목표·입력 경로·쓰기 범위·완료 조건만 전달하고 모델·권한 확인 전에 Task를 보내지 않는다. 전달이 모호하면 기존 세션을 확인하며 자동 재전송하지 않는다.

회수 결과는 변경 내용·요청 결과의 검증·미확인으로 제한한다. 기존 기획서에 짧게 합치며 날짜 보고·별도 리뷰·실행별 증빙을 만들지 않는다. 중요한 차단 원인과 실제 모델 불일치는 숨기지 않는다. 일반 논의의 자동 저장·범위 밖 실행·Git 권한을 추가하지 않는다.
