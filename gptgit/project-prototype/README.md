# project-prototype

승인된 작업을 작은 범위로 기획·제작·검증하는 시험 프로젝트다.

- 행동·권한: [AGENTS](AGENTS.md)
- 기획: [한 문서 양식](templates/development-plan.md)으로 목표·Task·결과를 함께 관리한다.
- 실제 개발 때만: [프로세스](docs/workflow.md)
- 담당을 실행할 때만: [실행 환경](docs/runtime.md)
- 재개할 때만: [작업기록](docs/records/work_log.md)의 최신 항목
- 지식이 필요할 때만: [위키](wiki/index.md)

목록은 읽기 순서가 아니다. docs/workflows의 실행별 명세·리뷰·시험·비용 자료와 구형 원장은 제거했다. 새 실행 폴더를 만들지 않는다.

변경: 2026-11-18 v0.7 — 한 문서 기획, 요청 결과만 검증, 실행별 자료 보관 폐지.
