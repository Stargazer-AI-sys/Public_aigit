# 위키 편집과 분류 기준

> 적용 버전: 0.1 | 적용일: 2026-11-06 | 원본 기준 버전: 0.2(2026-11-05)

위키는 원문을 통째로 옮기는 보관소가 아니라 이 프로젝트의 주제를 설명하는 탐색 창구다. 근거를 대조해 내용을 합성하며 시점·조건·예외·확정·제안·보류·미검증과 상충을 보존한다. 최신 사용자 지시와 이 프로젝트의 [작업 규칙](../AGENTS.md), 공식 기록이 우선한다.

실행별 원문과 증거는 해당 `docs/workflows/<실행ID>/`에 보존하고 위키 설명과 구분한다. 실행 기록이나 원본 docs를 위키가 대체하지 않으며 docs를 별도 raw로 이동하도록 강제하지 않는다. 인증정보를 기록하지 않는다.

구조 설명은 관계를 본문과 간단한 Mermaid로 함께 표현하고 목표 설계와 실제 연결·검증을 구분한다. 신규·변경 지식 문서의 메타데이터와 링크는 [스키마](../skills/wiki-editor/references/schema.md)를 단일 기준으로 삼고 [wiki-editor](../skills/wiki-editor/SKILL.md)를 적용한다. README·AGENTS·색인 같은 운영 파일에는 지식 문서 메타데이터를 요구하지 않는다.

| 폴더 | 답하는 질문 |
| --- | --- |
| features | 무엇을 어떤 조건에서 제공하는가? |
| architecture | 구성 요소가 어떻게 연결되는가? |
| decisions | 무엇을 왜 선택했고 영향은 무엇인가? |
| index | 필요한 주제와 문서가 어디에 있는가? |
| log | 언제 무엇이 발생하고 어떤 결과가 남았는가? |
| operations | 어떤 조건에서 어떻게 운영하고 확인하는가? |

분류 기준과 폴더 생성은 기존 자료의 내용별 재분류 또는 구현·시험 완료를 뜻하지 않는다. 형식 검사 외에 원문 맥락·정확성·도식 의미와 미검증을 별도로 확인한다.
