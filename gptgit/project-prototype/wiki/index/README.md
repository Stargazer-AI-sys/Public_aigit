# 위키 전체 색인

위키는 주제별 설명의 진입점이다. 현재 여섯 분류 폴더에는 담당 기준만 있으며 지식 문서의 분류·작성 완료를 뜻하지 않는다.

- [기능](../features/AGENTS.md): 제공 범위와 사용 조건.
- [구조](../architecture/AGENTS.md): 구성 요소와 관계.
- [결정](../decisions/AGENTS.md): 선택의 이유와 영향.
- [색인](AGENTS.md): 탐색과 위치.
- [이력](../log/AGENTS.md): 사건과 결과.
- [운영](../operations/AGENTS.md): 절차와 확인 조건.

프로젝트 자료는 [위키 시작점](../index.md)에서 찾는다. 실행별 상태와 증거는 해당 프로젝트 기록을 따른다.
