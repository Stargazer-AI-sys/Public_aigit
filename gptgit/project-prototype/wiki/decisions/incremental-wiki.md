# 간결한 위키 운영

작업 중 재사용할 지식이 확정되면 해당 분류의 기존 문서에 합친다. 한 앱에 분류별 한 문서를 기본으로 하고 Task마다 새 문서를 만들지 않는다. 비어 있는 분류는 생성하지 않는다.

위키는 필요한 때만 조회한다. 실행 절차를 따라 위키·색인·스키마를 순회하지 않는다. 작성은 Codex Luna 기본·복잡한 합성 Terra이며 Hermes 연결을 기다리지 않는다.

2026-11-18 사용자 요청으로 실행별 비용 분석·리뷰·시험 증빙 보관을 폐지했다. 검증은 요청 결과에 한정하고 기존 기획서에 결과·미확인만 짧게 남긴다. 상세 비용 수치는 보관하지 않는다. 이 규칙은 파일 감시나 자동 수집의 구현을 뜻하지 않는다.
