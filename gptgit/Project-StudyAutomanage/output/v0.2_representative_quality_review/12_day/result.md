# 12일차 — 새 흐름 적용 검토 결과

라우팅의 기본 기능과 경로 선택 기준을 복습하고, 정적·동적 라우팅 및 디폴트·플로팅 라우트 설정을 다룹니다.

> 저장 결과를 원문 대조 후 재구성한 검토용 결과입니다. 새 API 분석은 수행하지 않았습니다.

**게시 보류:** 디폴트 라우트·Stub network 단락의 보안·손실 단정은 아직 해결되지 않았습니다. 원문 주장으로만 읽어야 합니다.

## 라우팅 기본 기능과 네트워크 분리

라우팅 테이블을 기준으로 패킷을 특정 인터페이스로 출력하는 과정으로 설명됩니다.

물리적 분리 / 논리적 분리: 분리 기준

## IGP·EGP와 경로 계산 방식

IGP / EGP: 적용 범위, 라우팅 영역

Distance vector / Link state: 정보 교환 시점

❗ **정정** EIGRP는 링크상태 프로토콜이 아니라 거리 벡터 기반의 DUAL을 사용하는 프로토콜이다. [RFC 7868 — EIGRP architecture](https://www.rfc-editor.org/rfc/rfc7868.html)

## 정적 라우팅 설정

ip route 명령으로 목적지 네트워크와 출력 인터페이스를 지정하는 명령 예시가 있습니다. 실행 성공 여부는 제시되지 않습니다.

## 디폴트 라우트와 Stub network

자료에서는 외부와 통하는 인터페이스가 단 1개인 네트워크라고 정의합니다.

자료에서는 stub network가 모든 IP에 대해 패킷을 수신·송신한다고 설명하며 보안성이 없다고 서술합니다. 또한 인터페이스가 1개를 초과할 때 디폴트 라우트를 설정하면 패킷이 일부 소실될 수 있다고 설명합니다.

디폴트 경로 설정과 기존 정적 경로 삭제 명령 예시가 포함되어 있습니다. 실행 결과는 제시되지 않습니다.

## 최장 프리픽스·AD·메트릭

자료에서는 관리 거리이며, 특정 네트워크 정보를 2개 이상 경로로 학습한 경우 우선 경로를 판단하는 기준이라고 설명합니다.

자료에서는 테이블 룩업에서 프리픽스 길이를 비교하고, 이어서 AD가 낮은 경로와 cost가 낮은 경로를 우선하는 순서를 제시합니다.

❗ **정정** 동일 프리픽스의 경로 등록에는 AD·프로토콜별 메트릭을 고려하고, 패킷 전달 시에는 등록된 경로 중 최장 프리픽스를 선택한다. [Cisco — Configure Route Selection for Routers](https://www.cisco.com/c/en/us/support/docs/ip/enhanced-interior-gateway-routing-protocol-eigrp/8651-21.html)

## RIP 설정과 플로팅 라우트

목적지로 갈 수 있는 잉여 회선이 있는 경우 주 경로와 보조 경로를 지정하여 주 경로 장애 시 보조 경로가 동작하도록 하는 방식으로 설명합니다.

R1과 R2에서 RIP을 활성화하고 네트워크를 지정하는 명령 예시가 있습니다. 원격지 학습 결과는 제시되지 않습니다.

원문에서 보조 경로로 표시한 AD 10의 정적 경로 명령 예시다. 실제로 백업이 되는지는 주 경로와의 AD 비교가 필요하며 장애 전환 결과는 기록되어 있지 않다.

❗ **정정** 동일 프리픽스의 기본 RIP 경로를 주 경로로 삼으려면 백업 정적 경로 AD는 120보다 커야 하므로 AD 10은 그 조건에서 백업이 아니다. [Cisco — Configure Route Selection for Routers](https://www.cisco.com/c/en/us/support/docs/ip/enhanced-interior-gateway-routing-protocol-eigrp/8651-21.html)

## 남은 확인 사항

- 보안성 없음·패킷 절반 손실이라는 원문 단정의 근거와 관찰 원인이 확인되지 않았다.
- 말미의 불완전한 서브넷 계산은 완성하거나 검증된 계산으로 추가하지 않았다.
