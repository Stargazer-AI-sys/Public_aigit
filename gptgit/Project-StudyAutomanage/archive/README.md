# 과거 자료 보관

현재 실행 원본은 `../study/study-system/`입니다.

| 폴더 | 보관 대상 |
| --- | --- |
| versions | 이전 버전 소스 ZIP, 추출 시험 ZIP, 코드 검토 전 백업 |
| analysis_samples | 프로젝트 루트에 보관했던 과거 분석 JSON 및 추적 결과 |
| test_artifacts/runtime_test_tmp | 임시 화면 시험 소스, 추출한 화면 스크립트, 시험 로그와 측정 결과 |

`manifest.json`에 이동 전·후 경로, 파일 크기, SHA-256을 기록했습니다. 복원할 때는 실행 중인 작업을 종료하고 해당 항목의 `original` 경로에 파일을 돌려놓습니다. 같은 이름의 파일이 이미 있으면 덮어쓰지 말고 비교합니다. 보관된 임시 시험 스크립트는 당시 경로를 포함할 수 있으므로 현재 실행기로 사용하지 않습니다.

현재 검증에서 사용하는 `test_file/`, `tests/`, `fixtures/`, `.test-deps/`는 기존 위치를 유지합니다. 분석 캐시, 승인 저장소, Notion 게시 이력·전달 자료, Schema 및 과거 결과와 연결된 나머지 output 폴더도 유지합니다. `output/test_tmp/`의 하위 임시 폴더는 참조 여부가 확정되지 않아 이번 이동에서 제외했습니다. 공식 작업기록의 과거 경로 표기는 당시 이력이며, 이동된 파일은 manifest의 original 항목으로 찾을 수 있습니다.
