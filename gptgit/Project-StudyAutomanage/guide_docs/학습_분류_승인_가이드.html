학습자료 관리 실행 가이드

프로그램 실행 → 웹 화면에서 분석·사용자 승인 → 게시 미리보기 → 채팅 전송 중계

Windows의 기존 프로젝트 폴더와 Python 환경을 사용합니다. API 키는 처음 한 번 등록합니다. 이미 승인한 자료는 재분석하지 않습니다. 실제 Notion 전송은 현재 Codex 채팅의 중계를 유지합니다.

1. 프로그램 실행2. 최초 설정3. 자료 분석4. 승인5. 게시6. 오류·종료

1. 프로그램 실행

탐색기에서 프로젝트의 tools 폴더를 열고 run_study_manager.cmd를 더블클릭합니다.

프로그램이 로컬 서버를 실행하고 브라우저의 관리 화면을 자동으로 엽니다. 실행·승인 대기·게시·설정 탭을 사용합니다. 별도 명령어와 Ctrl+C 입력은 필요하지 않습니다. 실행 창은 프로그램을 사용하는 동안 열어 둡니다.

확인: ‘학습자료 관리’ 화면과 원본별 상태가 보입니다. 창을 다시 실행하면 기존 관리 화면을 엽니다. 자동으로 열리지 않으면 실행 창에 표시된 http://127.0.0.1:포트 주소를 사용합니다.

2. 최초 설정

  1. 설정 탭에서 API 키를 입력하고 이 PC에 안전하게 저장·교체를 누릅니다.
  2. 기본 새 API 호출 한도를 설정하고 설정 저장을 누릅니다. 기본값은 1회입니다.

확인: ‘API 키 등록됨’이 표시됩니다. 키는 Windows 자격 증명 관리자에 저장되며 재실행해도 재사용합니다. HTML·브라우저 저장소·프로젝트 파일에 키를 저장하지 않습니다. 화면에는 저장된 키를 다시 표시하지 않습니다.

다른 PC에서는 키를 다시 등록합니다. 키 저장만으로 유료 분석을 시작하지 않습니다. 키 교체·삭제도 이 탭에서 처리합니다. 프로그램은 현재 Windows 사용자 계정의 보호를 전제로 합니다.

3. 신규·변경 자료 분석

  1. TXT·DOCX 원본을 study/sourcefile/에 넣습니다.
  2. 실행 → 원본 다시 확인을 누릅니다.
  3. 신규·변경 자료 중 분석할 파일을 선택합니다.
  4. 이번 호출 한도를 확인하고 선택 자료의 유료 분석을 허용합니다에 체크한 뒤 선택 자료 분석을 누릅니다.

분석기(Analyzer)가 본문을 분석·분류합니다. 호출 한도는 성공 수가 아니라 새 요청 시도 수이며 기존 누적 예산 제한도 적용됩니다. 진행 중에는 중복 실행을 막습니다.

확인: 새 API 요청·성공·실패·차단 건수와 자료별 원인이 표시되고, 완료 후 승인 대기 탭으로 이동합니다. 한도 밖 자료는 다음 실행에 선택합니다. 실패를 자동으로 유료 재시도하지 않습니다.

4. 내용 확인과 승인

  1. 승인 대기 탭에서 자료의 검토 후 승인·보류를 누릅니다.
  2. 본문·분류·원문 인용과 안내를 확인하고 승인 또는 보류를 누릅니다.
  3. 승인하면 다음 대기 자료를 보여줍니다. 검토가 끝나면 게시 탭으로 이동합니다.

이 단계는 승인·보류용입니다. 원문·분류·본문을 직접 편집하지 않습니다. 게시에 영향 없는 보조 항목 오류는 제외 사유를 표시하고 유효한 본문은 승인할 수 있습니다. 구조·원문 근거·승인 유효성 오류는 해당 자료를 게시하지 않습니다.

확인: 승인한 자료가 대기 목록에서 빠지고 기존 승인은 유지됩니다. 화면을 닫거나 Ctrl+C를 눌러야 다음 단계로 넘어가는 절차는 없습니다.

5. 미리보기 확인 후 게시 중계

  1. 게시 → 미리보기 생성을 누릅니다.
  2. 게시 본문·분야 연결·화면 변경 수와 제외 자료·사유를 확인합니다.
  3. 현재 미리보기와 제외 자료를 확인했습니다에 체크합니다.
  4. 게시 준비 및 중계 요청 복사를 누릅니다.
  5. 프로그램을 켜 둔 채 현재 Codex 채팅에 복사된 문구를 붙여넣습니다. 자동 복사가 실패하면 요청 상자를 선택하고 Ctrl+C로 복사합니다.

미처리·실패·보류인 신규 자료가 있어도 게시 가능한 승인 자료는 진행합니다. 변경된 기존 승인본과 원본이 충돌하거나 기존 게시 범위를 보존할 수 없으면 해당 원인을 표시하고 준비를 멈춥니다. 제외 자료를 게시 성공으로 처리하지 않습니다.

확인: ‘Notion 게시 및 학습 화면 갱신 완료’가 표시되어야 완료입니다. ‘중계 대기’나 ‘일부 오류’는 완료가 아닙니다. 자료·승인·원본·설정이 미리보기 생성 뒤 바뀌면 새 미리보기를 생성합니다. 변경이 없으면 불필요한 본문 읽기·쓰기는 생략하며 목록 조회는 유지합니다.

완료 후 Notion PC 앱에서 Network 학습 자료의 홈 → 분야 → 해당 자료 링크가 열리는지 확인합니다. 분류 화면의 17개 항목과 기존 찾아보기는 유지합니다.

6. 오류 확인과 종료

  • 보조 항목 안내: 제외 원인을 확인하고 유효한 본문을 검토·승인합니다. 자동 재분석은 하지 않습니다.
  • 신규 자료 분석 실패: 화면의 오류 코드를 확인합니다. 해당 자료는 제외하고 정상 승인 자료의 게시 준비를 진행할 수 있습니다. 재시도가 필요하면 대상 선택과 한도를 확인한 뒤 ‘실패·중단 작업 재개’에서 실패 재시도를 명시합니다.
  • 기존 원본 변경 충돌: 변경 자료를 분석·승인한 뒤 다시 준비합니다. 오래된 승인본을 신규 결과인 것처럼 게시하지 않습니다.
  • 게시안 변경·전송 차단: 미리보기부터 다시 생성합니다.
  • 중계 시간 초과·응답 유실·잠금·수동 수정 충돌: 화면의 코드와 게시 패키지 경로를 Codex에 전달합니다. 이전 실행 종료·원격 상태 확인 후 게시 복구 옵션을 사용합니다. outbox·영수증·잠금을 임의로 삭제하지 않습니다.
  • 환경 오류: 실행 창의 Python·패키지 오류를 확인합니다. Windows 자격 증명 접근 오류는 일반 Windows 사용자 세션에서 실행했는지 확인합니다.

프로그램 종료 버튼으로 종료하고 브라우저 탭을 닫습니다. 작업 중에는 종료를 막습니다. 브라우저 탭만 닫으면 프로그램은 계속 실행 중이므로 실행기를 다시 열어 종료합니다.

실행 결과는 study/study-system/output/notion_live/manager/와 기존 runs/·prepared/에 남습니다. 실제 게시 완료와 문서 검사·모의 검증은 구분합니다.
