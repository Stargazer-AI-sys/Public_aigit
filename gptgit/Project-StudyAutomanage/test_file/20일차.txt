**예를 들어 RIP 를 학습한 라우터에서 OSPF로 학습된 라우터로 갈시 

aSw1
conf t
int fa1/1
sw mode acc
sw acc vlan 10
int fa1/2
sw mo acc
sw acc vlan 20
int fa1/15
sw mo tr

sh vlan-switch

 ASW2
conf t
int fa1/1
sw mode acc
sw acc vlan 10
int fa1/2
sw mo acc
sw acc vlan 20
int range fa1/14 - 15
sw mo tr

conf t
ip routing
vlan 10
int vlan 10
ip addr 192.168.10.254 255.255.255.0
vlan 20
int vlan 20
ip addr 192.168.20.254 255.255.255.0
in fa1/14
sw mo tr

설정 후 2가지 확인
1. sh int trunk : fa0/14포트가 trunk로 지정되어 있는지, 캡슐화 프로토콜은 무엇인지 확인
2. sh ip int b : vlan 10, vlan 20에 할당된 IP 및 SVI 활성화 여부 확인
