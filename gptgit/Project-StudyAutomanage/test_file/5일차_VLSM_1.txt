■ VLSM(Variable Length Subnet Mask)-가변 길이 서브넷 마스크
-서브넷팅을 했을 때 모든 서브넷이 획일적인 규모로 나뉘어지는 것은 아님.
-각 서브넷별 차등적인 IP가 필요할 수 있음.

주어진 네트워크 범위
-개발 : 192.168.1.0/26	 	0~63
-영업 : 192.168.1.64/26		64~127
-재경 : 192.168.1.128/27		128~159
-인사 : 192.168.1.160/27		160~191
-경영 : 192.168.1.192/27		192~223	
-공유링크 : 192.168.1.224/30	224~227
라우터 인터페이스에는 사용 가능한 마지막 주소 사용

R1
en
conf t
int fa0/0
ip addr 192.168.1.62 255.255.255.192
no shut
int fa1/0
ip addr 192.168.1.158 255.255.255.224
no sh
int fa2/0
ip addr 192.168.1.222 255.255.255.224
no sh
int s3/0
ip addr 192.168.1.225 255.255.255.252
no sh

R2
en
conf t
int fa0/0
ip addr 192.168.1.126 255.255.255.192
no sh
int fa1/0
ip addr 192.168.1.190 255.255.255.224
no sh
int s2/0
ip addr 192.168.1.226 255.255.255.252
no sh

■Routing Protocol구성
-원격지 네트워크 학습
R1, R2 공통 설정
en
conf t
router rip
net 192.168.1.0
no auto-summary
version 2



구성 후 R1, R2의 라우팅 테이블 확인
sh ip route		#라우팅 테이블 확인
Router(config-if)#do sh ip route
tracert 192.168.1.161	#경로 추적
