■ PW구성
Router(config)#enable pass 1111		#평문저장
Router(config)#enable secret 2222		#일방향 암호문 저장

■Mode Type
Router>enable					#User mode
Router#conf t					#Privileged mode
Router(config)#int Fa0/0				#Global mode
Router(config-if)#router rip			#Interface mode
Router(config-router)#line vty 0 4
Router(config-line)#end		Ctrl+C

■시간 설정(Time)

Router#sh clock

■Remote Access
-Telnet : TCP 23포트 사용, 메시지 평문 전송
-SSH : TCP 22포트 사용, 메시지 암호문 전송

■Telnet설정
-장비 이름 : 접근 장비의 이름 확인을 위해 필요
-특권 PW
-가상회선(VTY) 범위 설정 : 가상회선은 동시 접속 가능 회선을 의미
-가상회선 PW

Router(config)#hostname R1
R1(config)#enable secret 2222
R1(config)#Line vty 0 1
R1(config)#pass 3333
do sh run

■SSH설정
-장비 이름 : 접근 장비의 이름 확인을 위해 필요
-특권 PW
-가상회선(VTY) 범위 설정 : 가상회선은 동시 접속 가능 회선을 의미
-가상회선 PW
-도메인 정의
-로컬 계정 생성
-암호화 알고리즘, 키 길이 정의
R1
conf t
ip domain-name ict.ac.kr
username user1 pass 3333
crypto key generate rsa
line vty 0 2
login local

추가 설정
conf t
line vty 0 4

exec-timeout 2 30			#미입력시 세션 해제시간 설정	

■Backup
라우터와 스위치에 설정한 정보는 RAM에 저장됨. RAM은 휘발성이 있기 때문에 Rebooting되면 모든 설정이 삭제됨.
이런 문제를 예방하기 위해 NVRAM(비휘발성 RAM)에 백업하여 설정정보를 유지할 필요가 있음.
sh running-config		#RAM정보 확인

write				#RAM정보를 NVRAM에 백업
erase start			#NVRAM정보 삭제 명령
delete vlan.dat		#Vlan DB삭제 명령
