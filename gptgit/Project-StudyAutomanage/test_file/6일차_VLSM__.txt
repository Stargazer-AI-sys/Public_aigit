라우터의 필수 구성 2가지

1. Routed protocol : 패킷 전달시 목적지까지 전송되는 프로토콜
=>ip 설정을 의미함
=> 라우터에 직접 연결된 인터페이스에 주소할당
=> 라우팅 테이블에 코드 C로 표시

2. routing protocol : 원격지 네트워크 경로 학습용 프로토콜
- static : 관리자가 원격지 네트워크 정보를 수동으로 입력하여 학습
- dynamic : 라우터끼리 자신의 로컬 네트워크 정보를 교환하여 원격지 네트워크 정보를 학습
  bgp    Border Gateway Protocol (BGP)
  eigrp  Enhanced Interior Gateway Routing Protocol (EIGRP)
  ospf   Open Shortest Path First (OSPF)
  rip    Routing Information Protocol (RIP)
rip version 2 v4용
version 3 v6 용

classful 방식의 라우팅 프로토콜은 서브넷 마스크를 인식하지못함

VLSM_lab2 inter-vlan
-사내부서는 모두4개
-개발부(80대), 인사부(29), 영업부(60대), 회계부(25대)
-각 부서의 규모에 맞춰 서브넷팅을 해야됨
-회사가 ISP에서 할당받은 주소는 199.12.10.0/24

개발부(vlan10) : 199.12.10.0/25 199.12.10.1 ~ 127   GW 199.12.10.1
영업부(vlan20) : 199.12.10.128/26 199.12.129 ~ 191 GW 199.12.10.129
인사부(vlan30) : 199.12.10.192/27 199.12.193 ~ 223 Gw 199.12.10.193
회계부(vlan40) : 199.12.10.224/27 199.12.225 ~ 254 Gw 199.12.10.225

게이트웨이 주소는 1번째 유니케스트 아이피에 할당

스위치 > 4094 개 VLAN  인터페이스 총 갯수 12bit

백업
라우터와 스위치에 설정한 정보는 ram 에 저장됨. ram은 휘발성이 있기 때문에 Rebooting 되면 모든 설정이 삭제됨 이런 문제를 예방하기 위해 NVRAM(비휘발성RAM) 에 백업하여 설정정보를 유지할 필요가 있음
##특권모드에서 사용

sh runnin-config (sh run) #RAM정보 확인
sh startup-config #NVRAM 정보확인

장비 초기화 
RAM 은 리부팅하면 사라짐 NVRAM 은 erase start flash (do dir) 
wr RAM 정보를 NVRAM 에 백업
