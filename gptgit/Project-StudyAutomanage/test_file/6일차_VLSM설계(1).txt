Classful방식의 라우팅 프로토콜은 서브넷 마스크를 인식하지 못함.

■ 라우터의 필수 구성 2가지
1. Routed Protocol : 패킷 전달시 목적지까지 전송되는 프로토콜
 =>IP 설정을 의미함.
 =>라우터에 직접 연결된 인터페이스에 주소 할당
 =>라우팅 테이블에 코드 'C'로 표시
2. Routing Protocol : 원격지 네트워크 경로 학습용 프로토콜
 - Static : 관리자가 원격지 네트워크 정보를 수동으로 입력하여 학습
 - Dynamic : 라우터끼리 자신의 로컬 네트워크 정보를 교환하여 원격지 네트워크 정보를 학습

Q. 라우터 인터페이스에 할당한 서브넷 마스크값과 PC에 할당한 서브넷 마스크값이 다른 경우 어떤 현상이 발생하겠는가?
PC(200.1.1.30/27) <=> Router Fa0/0(200.1.1.1/28)
A. 양쪽 장비의 서브넷 마스크 값을 기준으로 상대방 IP를 포함하는 범위를 가지고 있으면 통신가능. 포함되지 않으면 통신 불가.
+++++++++++++++++++++++++++++++++++++++++
■VLSM_lab2 Inter-vlan
-사내 부서는 모두 4개
-개발부(80대), 인사부(29대), 영업부(60대), 회계부(25대)
-각 부서의 규모에 맞춰 서브넷팅을 해야 함.
-회사가 ISP에서 할당받은 주소는 199.12.10.0/24.

각 부서별 주소 할당 범위
-개발부(Vlan10) : 199.12.10.0/25, 0 ~ 127
-영업부(Vlan20) : 199.12.10.128/26, 128 ~ 191
-인사부(Vlan30) : 199.12.10.192/27, 192 ~ 223
-회계부(Vlan40) : 199.12.10.224/27, 224 ~ 255

게이트웨이 주소는 1번째 유니캐스트 IP할당

스위치는 기본적으로 모든 포트가 vlan1에 소속되어 있음.
