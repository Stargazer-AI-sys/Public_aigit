서브넷 마스크

IP 주소 공통(네트워크) 개별 (호스트)를 구분하기 위한 식 별 자
아이피와 서브넷은 항상 같이감
라우터는 서브넷마스크 범주내에서 계산함 고로 문제 풀때 서브넷 마스크 범주 외는 빼고 계산하기때문에 서브넷 범주가 24라면 뒤에 마지막 아이피 숫자는 0으로 처리

1. Default subnet mask : 클래스 기준으로 부여되는 서브넷 마스크
2. Extended subnet mask : 기본 서브넷 마스크에서 서브넷팅을 하는 경우 사용되는 서브넷 마스크 ★

슈퍼넷팅이나 서브넷팅을 주로 실무에서 사용되는 경우가 많음 (기본은 안쓴다고 함)

=> 시스템 숫자를 고려한 클래스 선택은 호스트 부분이 가장 작은 범위로 결정하는게 좋다(브로드캐스트 영역이 가장 작아야 좋다)
C클래스에서 보면 네트워크 범주 외 호스트 범주가 끝에 8비트(256) 범주로 잡고 여기서 서브넷팅으로 잡아주면 컴팩트하게 브로드캐스트 범주를 잡을수 있다. => 브로드캐스트 범주를 최적화 하는 용도가 바로 서브넷팅이다.
ex 5개 부서 -> 5개 서브넷팅 /27 범주면 8개까지 잡힘 그러면 5개 쓰고 나머지 추가될떄마다 3개범주에서 알아서쓴다

근대 만약 한쪽 부서에서 50개 호스트를 가지고 있다고 치자. 그럼 쪼갠부분에서 남은 부분에서 하나 더 합치면고 싶다면 슈퍼네팅이 필요함

■DHCP (Dynamic host configuration Protocol)
연결된 호스트에 대해 IP관련 설정 정보를 자동으로 할당하는 기능을 담당하는 프로토콜이다.
윈도우나 리눅스에서 별도로 만들어 할당하는 방법과 라우터에서 할당하는 방식이 있다.
