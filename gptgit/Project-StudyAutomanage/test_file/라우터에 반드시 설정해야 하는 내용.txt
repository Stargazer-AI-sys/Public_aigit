라우터에 반드시 설정해야 하는 내용
1. IP(Routed protocol)
2. Routing Protocol : 경로 (네트워크) 학습용 프로토콜
-> 로컬 2 원격 3 
-> 목적지를 알면 포워딩해주고 모르면 드롭 (라우터는 제어가 핵심인 장비이기에..)
-> 목적지 정보 관리는 라우팅 테이블을 통해서 이루어짐

라우터 설정 확인 명령어

do sh ip int b 전체 인터페이스 상태 확인

do sh ip route : 라우팅 테이블 확인

-> do 는 예시로 현재 프롬프트 창에서 인터페이스 작업중일때 show 명령어의 경우 상위 어드민 명령어이기때문에 끌어다가 써야됨 즉 현재 어드민 상태에서는 그냥 show 부터 시작하면 됨

라우터 핵심 기능
1. Packet switching : 패킷을 보낼지 말지를 결정 ★
2. path selection : 보낸다면 어떤 인터페이스로 보낼지 결정 ★

트러블 슈팅시에 경로 중도에 문제가 발생했다고 치면 라우팅 테이블을 확인해야된다
sh ip route

dst (목적지)
src (출발지)

■라우팅 프로토콜 종류
1. static : 원격지 네트워크를 관리자가 직접 지정
2. dynamic : 라우터간 정보 교환을 통해 학습

■라우팅 테이블
- 최적의 경로 정보만을 저장
=> 인간이 이용하는 네비게이션과 같은 개념
ex 192.168.2.0/24 [120/2<---거치는 hop수] 만약3개의 라우터가 서로 1hop으로 연결될때 중도에 거치는 2hop 
- 가능한 나머지 정보는 topology database 에 저장 
=> 이것은 최적의 경로가 문제가 생길시에 해당 데이터베이스를 이용해서 차선책을 이용할 수 있도록 하는 경로 정보
홉수를 기준으로 판단하는것은 rip 형식
