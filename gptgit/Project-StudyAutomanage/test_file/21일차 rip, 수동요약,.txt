sh ip protocol -> RIP 의 라우팅 테이블 업데이트 주기 등 각 항목별 타이머를 알 수 있다.
debug ip rip RIP 프로토콜에 대한 디버깅 모드 사용을 온 함으로써 RIP 로그가 나온다.
un all 디버그 모드를 끈다.

타이머 설정
router rip
ex. timer basic 90 270 270 640

router rip
version 2
network 10.0.0.0
network 192.168.12.0
no auto-summary
