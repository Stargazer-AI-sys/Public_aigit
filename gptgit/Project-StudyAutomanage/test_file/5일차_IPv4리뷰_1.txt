-네트워크 통신을 위해 필요한 요소
 1. 시스템	2. 매체(케이블)	3.프로토콜
-프로토콜 : 통신 규약, 통신 언어
 =>수만가지 프로토콜이 존재하며 목적에 따라 구분됨.
-IP
 =>대표적인 정보통신 식별자용 프로토콜
 =>IPv4, IPv6가 있음.
 =>IPv6는 IPv4 주소 고갈 문제를 해결하기 위해 개발

■ IPv4
-총 32bit로 구성되어 있음
-8bit씩 끊어서 Octet단위로 사용
 0000 0000=> 0
 1111 1111=> 255
 0.0.0.0 ~ 255.255.255.255
-네트워크 규모에 따라 5개의 Class로 나뉨.
-클래스의 구분은 MSB(Most Significant Bit-최상위 비트)
-A Class : 0
 =>1번째 옥텟이 같으면 동일 네트워크(LAN)
-B Class : 10
 =>2번째 옥텟까지 같으면 동일 네트워크
-C Class : 110
 =>3번째 옥텟까지 같으면 동일 네트워크
-D Class : 1110
 =>Multicast용도로 사용
-E Class : 1111
 =>학술 및 연구용으로 예약된 주소
-200.52.45.128
 200=> 128+64+8 = 1100 1000
-60.150.250.45
 60=> 32+16+8+4 = 0011 1100

-IPv4의 신호 종류
 1. Unicast : 1:1통신
 2. Multicast : 1:다수(Group)-특정 몇몇의 다수를 의미
  =>IGMP(Internet Group Management Protocol)
  =>SNMP(Simple Network Management Protocol)
 3. Broadcast : 1:all
  =>학습되지 못한 목적지 장비의 IP나 MAC주소를 확인하기 위해 모두에게 전송. 이 때 IRQ(Interrupt ReQuest-중단요청)가 발생되어 네트워크 전체 성능이 느려짐.

-Unicast를 하기 위해서는 학습기능이 있어야 함.
 =>Processor와 Memory가 필요
 =>Hub는 학습기능이 없다.
 =>스위치와 라우터는 학습 기능이 있다.

기본장치 : POST에 반드시 필요한 장치
 =>CPU, M/B, RAM, VGA
주변장치 : POST에 필수가 아닌 장치 
 =>마우스, 키보드를 포함한 나머지 모두

-IP와 Subnet mask
 =>IP는 장비 식별자로 사용.
 =>기본적으로 클래스별 공통부분과 개별부분으로 나뉨.

■Subnet Mask
IP주소에서 공통부분과 개별부분을 구분하는 구분자.
Default-subnet mask와 Extended Subnet mask로 나뉨.
-기본 서브넷 마스크 : IP Class에 따라 부여되는 값
  => A Class(/8), B Class(/16), C Class(/24)
-연장 서브넷 마스크 : IP Class와 상관없이 부여되는 값.
 =>기본 서브넷 마스크보다 작아지면 슈퍼넷, 커지면 서브넷
서브넷 마스크는 서브넷팅의 정보를 함께 보유함.
 => 192.168.1.5/26, 192.168.1.5/22
-서브넷 마스크는 반드시 IP와 함께 사용되며, 라우터의 경우 IP주소와 서브넷 마스크를 마스크 연산(AND연산)하여 서브넷 마스크가 이진수 1처리된 영역까지를 네트워크 부분(공통부분)으로 연산함.

192.168.1.5/25
1100 0000.1010 1000.0000 0001.0000 0101
1111 1111.1111 1111.1111 1111.1000 0000

■Subnet mask사용 규칙
1. 연속적인 이진수 1을 값만 사용
 =>서브넷 마스크값은 일정부분 정해져 있다.(0, 128, 192, 224, 240, 248, 252, 254, 255)
2. 이진수 1처리된 부분은 일치하는 부분(공통부분)으로 처리
3. 이진수 0처리된 부분은 불일치해도 되는 개별 부분으로 처리 

■Subnetting
Subnetting은 Broadcast domain을 효율적으로 사용하기 위해 사용되는 방법
=>PC가 10대인 사무실에서 C Class의 기본 서브넷 마스크를 사용하면 범위가 너무 넓게 된다.(256개의 IP를 단일 영역으로 생성)
-기본 서브넷 마스크에서 서브넷 비트를 2^n으로 추가.

 =>모두 1처리된 주소는 Broadcast IP

-LAN(Local Area Network) : 1:1로 직접 연결된 경우나 스위치/허브 등으로 연결된 네트워크로 단일 Broadcast Area에 속함.
-MAN(Metropolitan Area Network)
-WAN(Wide Area Network)

■Network에서 장비 식별용 프로토콜
1. IP : 논리적 주소.(변경 가능), 운영체제에서 부여
2. MAC : 물리적 주소. 네트워크 장비 생산 시 공장에서 ROM집적되어 출시. 변경 불가능. 총 48 bit로 구성. 앞에 24bit는 생산자 고유번호(OUI), 뒤에 24bit는 장비식별자.
3. Netbios : MS에서 개발. 컴퓨터 이름으로 해석(최대 255자)

ARP(Address Resolution Protocol)-주소 변환 프로토콜
IP=> MAC으로 변환
RARP(Reverse ARP) : MAC=> IP변환
