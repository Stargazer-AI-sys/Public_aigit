## R1·R2 인터페이스 및 RIP 설정

### 라우터 인터페이스 IP 주소 설정

R1의 Fa0/0에 192\.168\.1\.254/24, S1/0에 192\.168\.12\.1/24를 설정하고, R2의 Fa0/0에 192\.168\.2\.254/24, S1/0에 192\.168\.12\.2/24를 설정하는 명령 예시가 있습니다\. 각 인터페이스에 no shutdown 명령도 제시되어 있으나 실행 결과는 기록되지 않았습니다\.

### RIP 설정

R1은 192\.168\.1\.0 및 192\.168\.12\.0, R2는 192\.168\.2\.0 및 192\.168\.12\.0을 대상으로 router rip 아래에 network 명령을 입력하는 예시가 있습니다\. 설정 또는 라우팅 결과는 기록되지 않았습니다\.

### R1·R2 인터페이스 및 RIP 설정 예시

R1과 R2에서 Fa0/0 및 S1/0에 각각 주소와 마스크를 설정하고 no shutdown을 입력한 뒤, router rip 아래에 네트워크를 지정하는 명령 예시입니다\. 실행 여부나 라우팅 결과는 기록되지 않았습니다\.

원문 인용 · 표시본의 인증값은 숨김

```text
R1

conf t
int fa0/0
ip addr 192.168.1.254 255.255.255.0
no sh
int s1/0
ip addr 192.168.12.1 255.255.255.0
no sh
router rip
net 192.168.1.0
net 192.168.12.0

R2

conf t
int fa0/0
ip addr 192.168.2.254 255.255.255.0
no sh
int s1/0
ip addr 192.168.12.2 255.255.255.0
no sh
router rip
net 192.168.2.0
net 192.168.12.0
```

## SSH 구성과 접속 예시

### SSH 원격 접속

자료는 SSH를 암호문으로 통신하는 원격 접속용 프로토콜이라고 설명합니다\. R2에서 SSH 관련 설정을 제시하고 R1에서 R2 주소로 접속하는 명령을 적었으나, 접속 성공 여부는 확인되지 않았습니다\.

### SSH 구성 요소

구성 시 필요한 조건으로 로컬 계정, 특권 암호, 도메인 지정, 암호화 알고리즘과 키 길이 지정, 가상 회선 범위를 열거합니다\. R2 설정 예시에는 로컬 로그인과 VTY 범위가 포함되어 있으며 키 생성 명령은 물음표 도움말 표기에서 끝납니다\.

## IPv4 서브넷 마스크, 비트 표현 및 클래스

### IPv4 서브넷 마스크

자료는 192\.168\.1\.1/24의 주소와 마스크를 이진수로 적고, 마스크 연산을 AND 연산으로 설명합니다\. 또한 서브넷 마스크를 통해 주소를 매핑한다고 기록합니다\.

### IPv4 주소 클래스

자료는 IPv4 주소를 MSB로 식별하는 5개 클래스로 구분한다고 설명하며, 224\.30\.54\.70의 첫 옥텟 224를 1110 0000으로 나타내고 D 클래스라고 적습니다\. D 클래스는 멀티캐스트 용도, E 클래스는 학술 연구용 예약 주소라고 기록합니다\.

### IPv4 8비트 옥텟

자료는 IPv4의 옥텟을 8비트 구조로 제시하고 각 비트 값으로 128, 64, 32, 16, 8, 4, 2, 1을 나열합니다\.

### IPv4 주소 클래스

자료는 IPv4 주소를 MSB를 이용해 식별하는 5개 클래스로 구분한다고 설명합니다\. D 클래스는 멀티캐스트 용도, E 클래스는 학술 연구용 예약 주소라고 적고 있습니다\.
