## IPv4 클래스와 주소 용도

### IPv4 클래스

자료는 첫 비트 패턴에 따라 A\~E 클래스의 주소 범위를 나열하고, 클래스 구분 목적을 네트워크 규모에 따른 구분으로 설명한다\. D는 멀티캐스트용, E는 학술·연구용 예약 주소로 적고 있다\.

### IPv4 클래스 범위와 용도

자료는 클래스별 이진수 시작 패턴과 주소 경계를 제시한다\. 클래스 구분은 네트워크 규모에 따른 것이라고 설명하며, D는 멀티캐스트용, E는 학술·연구용 예약 주소로 서술한다\.

원문 인용 · 표시본의 인증값은 숨김

```text
0 111 1111.1111 1111.1111 1111.1111 1111 => 127.255.255.255

경우의 수 2^7 127개만큼 A클래스 네트워크 존재 

10 000 0000.0000 0000.0000 0000.0000 0000 => 128.0.0.0

```

## 서브넷 마스크와 네트워크 구분

### 서브넷 마스크

IP 주소에서 공통 네트워크 부분과 개별 호스트 부분을 구분하는 식별자다\. 자료는 연속된 이진수 1로 구성해야 하며, 1인 비트는 일치하고 0인 비트는 불일치해도 된다고 설명한다\. 클래스 기본 마스크와 서브넷팅에 사용하는 확장 마스크를 구분한다\.

### 서브넷 마스크

IP 주소의 공통 네트워크 부분과 개별 호스트 부분을 구분하는 식별자다\. 자료는 기본 서브넷 마스크를 클래스 기준으로 부여되는 마스크, 확장 서브넷 마스크를 기본 마스크에서 서브넷팅할 때 사용하는 마스크로 구분한다\.

원문 인용 · 표시본의 인증값은 숨김

```text
서브넷 마스크

IP 주소 공통(네트워크) 개별 (호스트)를 구분하기 위한 식 별 자
아이피와 서브넷은 항상 같이감
라우터는 서브넷마스크 범주내에서 계산함 고로 문제 풀때 서브넷 마스크 범주 외는 빼고 계산하기때문에 서브넷 범주가 24라면 뒤에 마지막 아이피 숫자는 0으로 처리

1. Default subnet mask : 클래스 기준으로 부여되는 서브넷 마스크
2. Extended subnet mask : 기본 서브넷 마스크에서 서브넷팅을 하는 경우 사용되는 서브넷 마스크 ★

슈퍼넷팅이나 서브넷팅을 주로 실무에서 사용되는 경우가 많음 (기본은 안쓴다고 함)
```

### 서브넷 마스크의 비트 규칙

서브넷 마스크는 연속적인 이진수 1을 사용해야 한다고 설명하며, 255\.255\.0\.255와 255\.255\.100\.0은 사용할 수 없는 예, 255\.255\.128\.0은 사용할 수 있는 예로 제시한다\. 마스크에서 1인 영역은 일치해야 하고 0인 영역은 불일치해도 된다고 적고 있다\.

원문 인용 · 표시본의 인증값은 숨김

```text
서브넷 마스크 사용 규칙
연속적인 이진수 1을 사용해야한다.
=>sm 255.255.0.255 XXX
=>sm 255.255.100.0 128자리에 0이 되서 사용불가
=>sm 255.255.128.0 사용가능
```

## 서브넷팅·슈퍼넷팅과 주소 할당

### 서브넷팅

클래스 기반 네트워크를 더 작은 네트워크로 나누어 브로드캐스트 영역을 줄이는 방법으로 설명한다\. 예제에서는 추가한 서브넷 비트로 서브넷을 구하고 호스트 주소 범위를 계산한다\.

### 슈퍼넷팅

자료는 연속된 여러 서브넷 또는 메이저넷을 합치는 것으로 설명하며, 추가 IP가 필요한 경우의 용도로 제시한다\.

### 유니캐스트 IP

자료에서 장비에 할당할 수 있는 호스트 주소를 유니캐스트 IP라고 부르며, 서브넷의 네트워크 주소와 브로드캐스트 주소는 할당 가능한 범위에서 제외한다\.

### 브로드캐스트 주소

서브넷 주소 범위의 끝 주소로 예제에서 표시되며, 장비 할당 주소 범위에서 제외된다\. 자료는 서브넷팅을 브로드캐스트 영역을 줄이는 용도로 설명한다\.

### 서브넷팅 → 브로드캐스트 주소

줄인다

자료는 서브넷팅을 브로드캐스트 영역을 줄이는 목적으로 사용한다고 설명한다\.

### 슈퍼넷팅 → 서브넷팅

합친다

자료의 정의에 따르면 슈퍼넷팅은 연속적인 여러 서브넷 또는 메이저넷을 합치는 방식이다\.

### 메이저 네트워크·서브네트워크·슈퍼네트워크

자료는 메이저 네트워크를 클래스를 그대로 사용하는 네트워크, 서브네트워크를 클래스를 쪼개 브로드캐스트 영역을 줄인 네트워크, 슈퍼네트워크를 연속적인 여러 서브넷 또는 메이저넷을 합친 네트워크로 정의한다\.

원문 인용 · 표시본의 인증값은 숨김

```text
메이저넷 서브넷 슈퍼넷

메이저 네트워크 : 클래스 그대로 사용
서브 네트워크 : 클래스를 쪼개서 브로드 캐스트 영역을 줄인 네트워크
=> 브로드캐스트 도메인 을 줄일 목적으로 사용 -> 서브넷팅
슈퍼네트워크 : 연속적인 여러개의 서브넷 또는 메이저넷을 합친 네트워크
=> 추가로 ip가 필요한 경우 사용 ->슈퍼넷팅
```

### 서브넷팅과 할당 가능 주소

자료는 서브넷팅으로 브로드캐스트 범위를 줄일 수 있지만, 서브넷을 나누면 각 구역에서 네트워크 주소와 브로드캐스트 주소를 장비에 할당할 수 없어 사용 가능한 주소가 줄어든다고 설명한다\.

## 사설 IP 주소와 공인 범위 메모

### 사설 IP 주소

자료는 공중망을 통과할 수 없고 IP 고갈에 대비해 만든 주소라고 설명하며, A 10\.0\.0\.0/8, B 172\.16\.0\.0/12, C 192\.168\.0\.0/16 대역을 열거한다\.

### 사설 주소 대역

자료는 사설 IP가 공중망을 통과할 수 없다고 설명하고 A 10\.0\.0\.0/8, B 172\.16\.0\.0/12, C 192\.168\.0\.0/16을 제시한다\. 공인 범위 메모에는 0\.0\.0\.0/8, 127\.0\.0\.0/8 및 사설 IP를 제외한다고 적혀 있다\.

원문 인용 · 표시본의 인증값은 숨김


### IPv4 주소 범위 계산

### 서브넷 수와 호스트 수 계산

요구되는 서브넷 수와 서브넷당 호스트 수에 맞춰 서브넷 비트와 마스크를 구하는 문제 유형을 다룬다\. 자료에는 /24를 여러 부서용으로 나누거나 점대점 링크용으로 나누는 예제가 포함되며, 일부 문제의 풀이가 완결되지 않았다\.
