**예를 들어 RIP 를 학습한 라우터에서 OSPF로 학습된 라우터로 갈시 

aSw1
conf t
int fa1/1
sw mode acc
sw acc vlan 10
int fa1/2
sw mo acc
sw acc vlan 20
int fa1/15
sw mo tr

sh vlan-switch

 ASW2
conf t
int fa1/1
sw mode acc
sw acc vlan 10
int fa1/2
sw mo acc
sw acc vlan 20
int range fa1/14 - 15
sw mo tr

conf t
ip routing
vlan 10
int vlan 10
ip addr 192.168.10.254 255.255.255.0
vlan 20
int vlan 20
ip addr 192.168.20.254 255.255.255.0
in fa1/14
sw mo tr

설정 후 2가지 확인
1. sh int trunk : fa0/14포트가 trunk로 지정되어 있는지, 캡슐화 프로토콜은 무엇인지 확인
2. sh ip int b : vlan 10, vlan 20에 할당된 IP 및 SVI 활성화 여부 확인


루프백 인터페이스로 가상의 장비를 추가했을때 핑테스트는
R1#ping 192.168.10.1 source 192.168.30.1
확장핑으로 소스 아이피를 기입해야된다.

R1
conf t
int fa0/0
no sh
ip addr 172.16.12.2 255.255.255.252
int L0
ip addr 192.168.30.1 255.255.255.0

router rip
net 172.16.0.0
net 192.168.30.1

DSW1
conf t
int fa1/1
no sw
ip addr 172.16.12.1 255.255.255.252
router rip
net 172.16.0.0
net 192.168.20.0
net 192.168.10.0

[경로 재분배]:서로 다른 라우팅 프로토콜(예: OSPF, EIGRP, RIP, BGP 등)을 사용하는 네트워크 간에 경로 정보를 번역하고 공유하여, 한쪽 프로토콜이 학습한 네트워크 정보를 다른 쪽 프로토콜로 전달하는 기능입니다. 정적으로는 안해준다.
