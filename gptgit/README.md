# GPT 작업 공간

> 문서 버전: 0.6 | 최초 작성: 2026-10-15 · 최종 수정: 2026-11-06 (한국 시간)

## 목적과 적용 범위

이 폴더는 Aigit 저장소 안에서 GPT 관련 프로젝트를 관리하는 최상위 작업 공간이다. GPT 공통 운영 방법은 이 문서에, AI 행동 규칙은 [AGENTS.md](AGENTS.md)에 둔다. 개별 프로젝트의 목적·상세 규칙·작업기록은 해당 프로젝트에서 관리한다. 이 규칙은 형제 폴더인 Claudecode에 자동 적용하지 않는다.

## 저장소와 동기화 운영

- GitHub의 원격 Aigit 저장소에 최신 작업을 반영해 중앙 공유 기준으로 사용하고, 각 PC의 로컬 복제본에서 작업한다. 로컬 작업과 GitHub 동기화를 기본 운영 방식으로 삼는다.
- 처음 사용하는 PC에서는 clone하고, 작업 시작 시 로컬 변경 상태를 확인한 뒤 pull로 원격 변경을 가져온다.
- 로컬 작업과 검증을 마친 뒤 반영할 파일을 선별하여 commit하고 push한다. 다른 PC로 옮길 때는 필요한 변경을 push한 뒤, 옮긴 PC에서 pull하여 이어간다.
- 로컬 미완료 변경이나 충돌이 있으면 내용을 확인하여 보존·통합한다. 임의로 덮어쓰거나 삭제하지 않는다.
- 위 절차는 사용자의 운영 방법이다. AI에게 Git 작업을 자동 실행하도록 허용하는 지시가 아니다. AI 실행 조건은 AGENTS를 따른다.
- GPT 규칙의 적용 범위는 gptgit이지만 Git 저장소 단위는 상위 Aigit 전체다. commit에는 해당 작업의 파일만 포함한다.
- 웹 Library는 필요할 때만 사용하는 보조 수단이며 정기적인 갱신 대상으로 두지 않는다. Git과 자동 동기화되지 않으므로, 웹을 다시 사용할 때는 GitHub와 동기화한 로컬 최신 내용을 기준으로 필요한 자료를 별도로 반영한다.

자료 폴더에 개발 프로젝트용 docs·AGENTS·인계 사본을 일괄 생성하지 않는다. 실제 작업을 요청받으면 목적과 원본을 확인해 필요한 구조만 추가한다. 위 표는 위치와 흐름의 안내이며 상세 진행 상태는 각 프로젝트의 공식 원본에서 확인한다.

문서 책임·재개·스킬 생성 검증·인계의 공통 기준은 [공통 작업 흐름](docs/common_workflow.md)에 두고 각 프로젝트에는 고유 절차만 남긴다.

## 공통 스킬

가이드 작성·수정은 [simple-user-guide](skills/simple-user-guide/SKILL.md), 초기 기획·요구사항 구체화는 [project-planning](skills/project-planning/SKILL.md), 인계 점검·재개는 [project-handoff](skills/project-handoff/SKILL.md)를 gptgit 하위 프로젝트에서 공통으로 사용한다. 세 공유 원본은 상위 `skills/`에서 관리하고 프로젝트마다 사본을 만들지 않는다.

사용 조건과 생성·검증·보고 기준은 [공통 AGENTS](AGENTS.md)를 따른다. 개인 설치·자동 등록과 개별 프로젝트의 실제 동작 검증 완료를 의미하지 않는다. 형제 Claudecode 및 gptgit 밖의 별도 저장소에는 자동 적용하지 않는다.
