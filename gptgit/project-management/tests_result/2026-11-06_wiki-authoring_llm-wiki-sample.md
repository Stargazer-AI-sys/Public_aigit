# LLM wiki 작성 테스트: 원문에서 설명으로

이 문서는 herdr 담당 분담을 시험하기 위한 샘플이다. 이 프로젝트의 위키 편집 규칙을 설명하며, 모든 LLM 위키 제품의 일반 사양을 뜻하지 않는다. 정식 위키로 게시하거나 전체 자동화 운영을 검증한 결과도 아니다.

## 원문 보관과 설명의 차이

이 프로젝트의 LLM 위키는 원문을 통째로 옮겨 보관하는 곳이 아니라 주제별 개념과 맥락을 설명하는 문서다. 원래 구조를 보존하는 역할은 raw가 맡으며, 위키 편집 과정에서 이 보관 원본을 수정·이동·삭제하지 않는다. 위키는 실행 기록이나 개별 프로젝트의 공식 상태를 대신하지 않는다. 근거: [위키 편집 기준 0.2](../wiki/AGENTS.md).

내용을 합성할 때는 원문의 절과 주장을 내용 단위로 나누고 관련 근거를 대조한다. 하나의 원문을 여러 주제로 풀거나 여러 원문의 내용을 한 주제로 묶되, 파일 종류보다 내용이 답하는 질문을 기준으로 분류한다. 각 주장에는 확인 가능한 출처를 연결하고 시점·적용 조건·확정과 제안·보류·미검증 상태를 유지한다. 과거 설계를 현재 기능처럼 설명하지 않으며 충돌이나 확인하지 못한 부분은 명시한다. 근거: [위키 편집과 내용별 분류](../wiki/AGENTS.md).

## 작성과 검토

1. 관련 원문과 기존 페이지를 읽고 설명할 주제를 정한다.
2. 중복을 줄여 설명문을 합성하고 주장 가까이에 근거를 연결한다.
3. 스키마에 맞게 메타데이터·출처·상대 링크를 작성하고 변경한 파일을 지정해 형식을 검사한다.
4. 원문과 설명을 별도로 대조해 누락·왜곡·상충 및 상태 보존을 검토한다.
5. 실제 검사 결과와 제외·미확인 범위를 보고한다.

위 흐름의 근거는 [wiki-editor 0.1](../skills/wiki-editor/SKILL.md)이다. 이 샘플은 개념 설명으로 `type: concept`를 사용한다. 정식 위키의 운영 절차 페이지를 추가하는 작업은 이번 시험 범위가 아니다.

## 검사의 한계

형식 검사는 YAML 필드·허용값·날짜, 출처와 상대경로, H1 및 코드 펜스 등을 확인한다. 형식 통과만으로 사실·최신성·원문 조건 보존·설명 품질이 보장되지는 않는다. 앵커, 외부 URL 접근, Mermaid 문법·화면·의미 등은 검사기에서 제외한다. 이번 샘플에는 도식을 넣지 않았으며 화면 렌더링 시험은 범위 밖이다. 근거: [위키 스키마](../skills/wiki-editor/references/schema.md).

페이지의 reviewed는 지정 원문을 읽고 설명에 반영했다는 상태다. 독립 내용 검토와 형식 검사의 실제 결과는 별도 테스트 결과 보고에서 구분한다.
