# 위키 편집

버전 0.1 · 2026-11-05 · project-management 전용

요청과 적용 권한을 확인하고 대상 프로젝트의 README·AGENTS를 읽는다. 이 프로젝트에서는 `wiki/AGENTS.md`가 내용 분류 기준의 단일 원본이다. 분류를 이 스킬에서 별도로 정하지 않는다. 기존 raw는 보존하고, 파일 수정·Git 등은 해당 프로젝트와 사용자의 권한을 따른다.

1. 관련 원문과 기존 페이지를 찾아 주제와 중복 여부를 판단하고, 기존 내용을 우선 갱신한다. 원문의 시점, 조건, 보류, 예외, 상충 및 미검증을 유지한다.
2. 자료 목록만 나열하지 않고 독자가 이해할 수 있도록 설명을 합성한다. 사실·사용자 보고·추정·제안을 구분하고 주장 가까이에 근거를 연결한다. 자료가 부족하면 확인 필요로 표시한다.
3. [스키마](references/schema.md)를 읽고 유형에 맞는 [틀](assets/templates/)을 필요한 만큼 적용한다. 구조 페이지의 도식은 실제 확인된 내용과 제안을 구분하고 근거를 연결한다. 신뢰도·검토 여부는 실제 증거로 판단한다.
4. 변경한 페이지와 관련 링크를 검토하고 지정 파일만 검사한다. 프로젝트 루트에서 실행:

   ```powershell
   .local/wiki-editor-venv/Scripts/python.exe skills/wiki-editor/scripts/check_wiki.py wiki/example.md
   ```

   PyYAML이 있는 다른 Python도 가능하다. 결과의 제외 범위를 확인하고 형식 통과를 내용의 정확성, 도식의 정확성, 출처의 진위나 최신성 검증으로 취급하지 않는다. 검사 결과와 미확인 사항을 보고한다.

이 스킬의 설치·등록이나 다른 프로젝트의 규칙 변경은 자동으로 수행하지 않는다.
