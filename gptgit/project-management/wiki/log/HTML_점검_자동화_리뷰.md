# 2026-10-15 HTML 점검 자동화 리뷰

이 개인 열람용 리뷰는 HTML 가이드를 쓴 뒤 AI가 구조를 한 번 검사하고 결과를 보고하는 절차를 실제 작업에 적용한 기록이다. 공통 절차를 한 곳에서 관리하면 검사 방법을 반복해서 정할 필요가 줄고, 무엇을 검사했는지 근거를 남길 수 있다는 당시 평가를 담는다. 운영 규칙이나 공식 인계를 대신하지 않는다. [원본 리뷰](../../raw/review_docs/HTML_점검_자동화_리뷰.md)

새 가이드 한 파일에 검사기를 한 번 실행해 상대 링크 4곳, 목차 연결 3곳, ID 3개를 확인했다. `CHECKED_ITEMS_OK`, 종료 코드 0, 검사 전후 파일 무변경으로 기록됐다. 초기 PowerShell 버전·실행 정책·상대경로 문제 때문에 사용자 터미널과 AI 환경의 실행 결과를 별도로 확인해야 했다. 이후 상대경로 우선 원칙은 [과거 관리 이력](../../raw/docs/04_records/management_history_2026-10-13_2026-11-02.md)의 2026-10-27 절과 현재 규칙을 대조한다.

이 가이드에서 작성 오류가 발견되지 않았으므로 오류 감소 효과는 입증되지 않았다. 앞선 오류 감지용 시험 12개와 실제 가이드 1회 검사는 다른 결과다. 시간·토큰 절감은 측정하지 않았고, 구조 검사는 내용 정확성과 화면 품질을 대신하지 않는다. [관리 이력 원문](../../raw/docs/04_records/management_history_2026-10-13_2026-11-02.md)
