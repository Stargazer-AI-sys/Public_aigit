# 프로젝트 관리 wiki

> 색인 갱신: 2026-11-05

이 위키는 원본 내용을 주제별로 분해·합성해 설명한다. [전체 문서 색인](index/README.md)에서 기능·구조·결정·운영·기록 문서를 찾고, [내용 분류표](index/content_classification.md)에서 원문 절과 설명 페이지의 대응을 확인한다. 편집 기준은 [wiki/AGENTS](AGENTS.md)를 따른다.

- 현재 작업 절차: [관리 워크플로](operations/management_workflow.md)
- 목적·범위 입력: [요구사항 작성 양식](features/신규_개발_프로젝트_요구사항_작성양식.md)
- 개설·선택의 제공 범위: [프로젝트 진입점](features/project_entry.md)
- 과거 설계 이해: [자동화 구조](architecture/automation_workflow.md)와 [역할 관계](architecture/roles.md)
- 당시 시험 근거: [자동화 검증 이력](log/automation_validation_history.md)

[raw](../raw/)는 과거 원본을 원래 구조로 보존한다. 위키 설명은 실행 기록이나 개별 프로젝트의 공식 상태를 대체하지 않는다. 현행 권한·위임은 [프로젝트 규칙](../AGENTS.md), 최신 역할·남은 업무와 보류는 [관리 작업기록](../docs/04_records/management_log.md)을 따른다.

자동화 운영은 현행 기능이 아니다. 도식·문서·로컬 시험은 실제 모델 연결, 독립 QA 또는 전체 프로토타입 완주 증거와 구분한다. 기존 가이드 정식 제작과 자료 전송 보류를 유지하며, 위키 편집을 이유로 프로토타입의 남은 8개 업무를 재개하지 않는다.
