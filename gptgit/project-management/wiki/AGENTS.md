# 위키 편집과 분류 기준

> 버전: 0.2 | 최종 수정: 2026-11-05 | 적용: 이 관리 프로젝트의 wiki

위키는 원본 문서를 통째로 옮기는 보관소가 아니라 주제별 내용을 설명하는 문서다. 원본의 절과 주장을 내용 단위로 분해하고, 관련 근거를 대조해 필요한 주제로 합성한다. 한 원본에서 여러 주제를 설명하거나 여러 원본을 한 주제로 합칠 수 있다. 문서는 개념과 맥락을 이해할 수 있는 설명문으로 작성한다.

- 각 주장에 확인 가능한 원본과 근거를 연결하고 시점·적용 범위·조건·확정/제안·보류·미검증을 보존한다. 최신 사용자 지시와 현행 규칙, 공식 상태 기록을 대조해 과거 설계와 현재 기능을 혼동하지 않는다. 충돌이나 확인하지 못한 내용은 명시한다.
- `raw/`는 원래 구조를 보존하는 보관 원본이며 위키 편집 과정에서 수정·이동·삭제하지 않는다. 실행 기록과 개별 프로젝트의 공식 상태를 위키가 대체하지 않는다.
- 구조와 구성 요소의 관계를 설명하는 architecture 문서는 필요한 흐름을 간단한 Mermaid 도식과 본문으로 함께 설명한다. 목표 설계와 실제 연결·검증을 구분한다.
- 메타데이터·출처·링크의 형식은 [스키마](../skills/wiki-editor/references/schema.md)를 단일 기준으로 삼고 [wiki-editor](../skills/wiki-editor/SKILL.md)를 적용한다. 각 폴더의 AGENTS는 고유 담당 범위만 정한다. 파일 수정과 위임 권한은 [루트 AGENTS](../AGENTS.md)를 따른다.
- 형식과 링크 검사 외에 원본 맥락·설명 정확성·상태와 도식의 의미를 별도로 검토한다. 규칙 마련은 기존 위키 재분류나 실제 구현·검증 완료를 뜻하지 않는다.

## 내용별 분류

원본 파일의 종류가 아니라 해당 내용이 답하는 질문으로 분류한다. 스키마의 문서 유형은 작성할 문서의 형식을 나타내며 폴더 분류와 구분한다. 하나의 원본은 여러 주제에 사용될 수 있다.

| 폴더 | 내용이 답하는 질문 |
| --- | --- |
| features | 무엇을 제공하며 어떤 조건에서 사용할 수 있는가? |
| architecture | 구성 요소가 어떻게 연결되고 어떤 구조로 작동하는가? |
| decisions | 무엇을 왜 선택했으며 어떤 영향을 주는가? |
| index | 필요한 주제와 문서를 어디서 찾는가? |
| log | 언제 무엇이 일어났고 어떤 결과가 남았는가? |
| operations | 어떤 조건에서 어떻게 운영하고 확인하는가? |
