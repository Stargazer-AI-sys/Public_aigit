## 2026-11-19 최신 인계: prototype 프로세스·산출물 축소

- **완료:** 사용자 요청으로 project-prototype의 실행별 자료 49개를 포함한 총 89개 파일을 삭제했다. 비용 분석·측정 도구, 구형 workflow 원장, 중복 지침·위키 스키마·서식 검사기를 제거했다. 상세 비용 자료는 다시 기록하지 않는다.
- **현재 기준:** 기획은 한 파일에 목표·구조·Task·완료 조건·짧은 결과를 모은다. 검증은 요청 결과와 직접 영향받은 동작에 한정한다. 위키는 분류별 기존 문서에 합치고 필요할 때만 조회한다. 현재 설명 문서는 3개이며 빈 분류 문서는 만들지 않았다.
- **유지:** 실행 설정·입력 JSON과 중복 실행 방지용 로컬 영수증·해시는 실제 제어에 필요하므로 남겼다. 실행별 리뷰·시험·비용 증빙 폴더는 다시 만들지 않는다.
- **검증:** 직전 작업에서 문서 연결, 수정 스킬 2개의 형식, 단일 기획서 packet 입력, diff 공백 검사를 통과했다. 실제 모델 호출·전체 프로세스 시험·commit·push는 하지 않았다. 이번에는 이 관리 작업기록만 갱신했다.
- **다음 작업:** 사용자가 지정한 결과만 구현·검증한다. 아래 과거 기록의 증빙 보관·전체 시험·구형 원장 유지 지시는 현행 절차가 아니다. 원본은 [프로토타입 작업기록](../../../project-prototype/docs/records/work_log.md), 기획 양식은 [단일 개발기획서](../../../project-prototype/templates/development-plan.md)를 참조한다.

- **확인 근거:** 최종 실행 근거(2026-11-18 사용자 요청으로 상세 자료 삭제), 실제 Claude 응답(2026-11-18 사용자 요청으로 상세 자료 삭제), 최종 dispatcher 영수증(2026-11-18 사용자 요청으로 상세 자료 삭제)을 읽고 대조했다. 최종 시험은 dispatcher exit 0 → 새 담당 탭·Claude 시작 → 실제 모델·권한 확인 → Task 1회 전달 → 응답 회수·내용 확인까지 복구 명령 없이 완료된 기록이다. 영수증의 submitted_unverified만으로 완료 판정하지 않았다.
- **이번 직접 확인과 한계:** 현재 dispatcher 코드·시험·최종 packet의 SHA-256 세 개가 실행 근거의 고정 해시와 모두 일치했다. 회귀 25건 통과와 별도 Terra 읽기 전용 검토 PASS는 당시 실행 기록으로 확인했다. 이번 확인에서는 기능 시험·모델 호출을 재실행하거나 기존 세션의 생존을 조회하지 않았다. 실제 정상 실행 근거는 해당 PC의 최종 시험 1회이며 다른 PC에서는 로컬 설정·설치·구독·herdr 상태를 다시 확인한다.
- **남은 작업:** 기존 목록의 3번 기획 작성↔Claude 검토 루프, 4번 병렬 담당 운영 보완·검증, 5번 자동 결과 회수·세션 재사용 구현, 6번 개발↔독립 QA 루프, 7번 Hermes 문서화 연결, 8번 전체 프로세스 완주가 남았다. 이번 dispatcher 코드의 독립 검토를 6번 전체 루프 완료로 계산하지 않는다. 관리 위키의 Mermaid 도식 6개 화면 확인도 별도 미검증이다.

- **보류·권한:** 가이드 정식 제작·기존 자료 전송 보류, 구독 범위·모델/권한 확인·담당 새 탭 정책을 유지한다. 이번에는 이 관리 인계만 갱신하며 commit·push는 수행하지 않았다. 아래 과거 8개 목록과 미검증 표시는 당시 상태이며 이번 최신 인계와 대상 원본을 우선한다.

## 2026-11-06 이전 인계: 공통 담당 관리·모델 제한·새 탭·훅 적용

- **완료:** [공유 delegation-reporting 0.4](../../../skills/delegation-reporting/SKILL.md), [실행 참고](../../../skills/delegation-reporting/references/runtime.md), 공통 모델 검사·관리 시작 backend·보조 훅을 구성하고 두 프로젝트에 연결했다. 관리 시작기는 [start_agent.ps1](../../tools/start_agent.ps1), 프로토타입 상세 적용 상태는 [해당 공식 작업기록](../../../project-prototype/docs/records/work_log.md)이 원본이다. 공통 AGENTS 0.4, 관리 AGENTS 0.23·README 0.27, 프로토타입 AGENTS/README 0.4를 기준으로 한다. 개인 설치·앱 등록은 하지 않았다.
- **확정 운영:** Astra는 마스터 전용, 하위 Codex는 명시적인 Luna·Terra로 시작하고 실제 모델·권한 확인 후 Task를 전달한다. Claude 기획 검토/개발과 Hermes 문서화 등 프로젝트별 역할은 유지한다. **마스터 대화 탭을 분할하지 않고 담당용 새 탭을 생성한 뒤 그 안에서만 pane을 분할한다.** 같은 작업 묶음의 담당 탭은 상태 확인 후 공유할 수 있다. 관리의 report_docs 날짜 보고 권한은 유지하되 프로토타입은 기존 실행 원장·공식 기록에 남긴다.
- **시험과 정정:** 앞선 [LLM wiki 6담당 테스트](../../tests_result/2026-11-06_agent-orchestration_llm-wiki-test.md)는 기본 모델을 상속한 Astra 6세션의 소규모 제어·작성 시험이었다. 역할별 모델 배분이나 정식 전체 프로세스 검증이 아니며, 당시 동일 탭 분할 방식은 이후 확정된 새 탭 정책으로 대체된다. 과거 시험 결과를 새 정책으로 소급 수정하지 않는다.
- **검증 근거:** 공통 시험 15건, 프로토타입 전체 회귀 58건 통과. 이후 마지막 탭 ID 검증 보완은 dispatcher 13건 한정 재검사로 통과했다. 공유/두 로컬 스킬 기본 검사 각각 exit 0. 독립 read-only Terra 검토에서 발견한 기존 탭 반환 검증 누락을 수정·재검토해 해결했다. 관리 QA 옵션 충돌 및 Windows PowerShell 정상 로그인 stderr 처리 문제도 수정했다. 상세 담당별 근거는 [11월 6일 보고](../../report_docs/2026-11-06.md)에 있다. 이번 인계 저장에서 기능 시험을 재실행한 것은 아니다.
- **실제 연결:** 관리 시작 도구의 Luna 새 탭 생성·Task 미전달 반환, 프로토타입 start_role의 Luna 기동·대기·권한 확인을 수행했다. 두 프로젝트에서 훅 등록·신뢰와 금지 모델 명령의 실제 PreToolUse 차단을 확인했다. 존재하지 않는 pane ID를 안전장치로 사용했으며 금지 모델을 호출하지 않았다. 프로토타입 dispatcher --apply의 실제 전체 전달은 미검증이며 start_role 기동 성공과 구분한다.
- **환경·한계:** 이번 PC에서 시스템 Python 3.14.8/PyYAML 6.0.3을 확인했다. 관리의 과거 .local/wiki-editor-venv 실행기는 부재해 시스템 Python으로 위키 샘플을 검사했다. 훅의 현재 절대경로·신뢰는 PC 이동 시 재확인이 필요하다. 훅은 모든 별칭·동적 코드·다른 실행 경로를 막는 보안 경계가 아니며 오류 시 fail-open이다. Claude/Hermes 실연결·전체 프로세스 완주·Mermaid 화면 검증은 미완료다.
- **마지막 세션 상태:** 마스터 w6:t1/p1은 pane 1개를 유지했고, 담당 탭은 w6:t2(p9/pA, Terra 제작), w6:t3(pB, Terra 독립 QA), w6:t4(pC, 관리 Luna), w6:t5(pD, 프로토타입 Luna)였다. 이는 직전 관측값이며 재개 시 생존·프로젝트 cwd·모델·권한을 다시 확인한다. 기존 창·서버를 임의 종료하거나 이전 Astra 담당을 그대로 재사용하지 않는다.
- **다음 행동:** 마스터가 사용자가 지정하는 후속 Task의 목표·범위·완료 조건과 대상 프로젝트 규칙을 확인한다. 승인된 실행이면 명시 모델과 입력/쓰기 범위를 준비하고 시작 도구 검사 → 새 담당 탭 → 실제 모델/권한 확인 → 최소 Task 전달 → 결과 회수·검토 순서로 진행한다. 실제 dispatcher 연결 시험을 선택하면 프로토타입의 실행 환경과 자체 명세부터 확인하며 이번 인계만으로 자동 착수하지 않는다.
