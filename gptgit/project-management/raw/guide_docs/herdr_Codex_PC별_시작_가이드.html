프로젝트 관리 · v1.1 · 2026-11-02

herdr · Codex 시작 가이드

기존 PC는 바로 실행하고, 새 PC는 처음 한 번 준비한 뒤 실행합니다.

Windows x64 PC 기준입니다. 아래 명령은 PowerShell 7 명령 창에 입력하세요. AI 대화 입력칸에는 넣지 않습니다. 이 문서는 herdr와 Codex 시작까지 안내합니다.

1. 기존 PC2. 다른 PC에서 처음 시작3. 실행이 안 될 때

1. 기존 PC에서 작업하기

Step 1. 프로젝트 폴더에서 PowerShell 열기

파일 탐색기로 project-management 폴더를 엽니다. 주소창에 pwsh를 입력하고 Enter를 누릅니다.

폴더 안에 README.md와 tools가 보이면 맞는 위치입니다. PC가 바뀌면 폴더 위치도 달라질 수 있습니다.

Step 2. herdr 열기

& ./.local/bin/herdr/herdr.exe --session project-management

--session은 작업 공간 이름입니다. 확인: herdr 화면이 열립니다. 기존 Codex 창이 있다면 그 창부터 확인합니다.

Step 3. herdr 안에서 프로젝트 위치 확인하기

herdr 안의 PowerShell 창에서 입력합니다.

Get-Location

현재 프로젝트 폴더가 아니면 탐색기에서 폴더 주소를 복사해 아래 따옴표 안에 넣습니다.

Set-Location -LiteralPath "복사한 프로젝트 폴더 주소"

Step 4. Codex 실행하기

./tools/start_master.ps1

시작기가 현재 Codex 설치 위치를 찾고 로그인 상태를 확인합니다. 확인: Codex 대화 입력 화면이 나오면 성공입니다. 같은 프로젝트의 Codex가 이미 실행 중이면 새로 시작하지 않고 기존 창을 유지합니다.

로그인이 필요하다고 나오면 ./tools/start_master.ps1 -LoginCodex를 실행해 ChatGPT 계정으로 로그인한 뒤 다시 실행하세요.

앱 업데이트 뒤에도 같은 명령을 사용합니다. 실행이 안 되면 3번의 점검을 따라 합니다. 이미 사용 중인 Codex 창은 닫지 마세요.

Step 5. 작업기록 읽고 시작하기

Codex의 대화 입력칸에 다음 문장을 보냅니다.

README와 AGENTS, 최신 작업기록을 읽고 완료·남은 작업·보류를 정리해줘.
아직 파일 수정이나 설정 변경은 하지 마.

이 시작기는 관리 프로젝트용입니다. 별도 프로젝트 폴더에 복사해 사용하지 않습니다. 이전 대화의 검증된 연결 기록이 있을 때만 ./tools/start_master.ps1 -ResumeSaved로 재개합니다. 연결 기록이 없으면 위 문장으로 작업기록을 읽어 시작하세요.

2. 다른 PC에서 처음 시작하기

Step 1. 프로젝트 파일 가져오기

Git PC 작업 가이드의 새 PC 준비 절차로 Aigit 저장소를 가져옵니다. 이미 가져왔다면 중복으로 만들지 않습니다.

확인: Aigit → gptgit → project-management 안에 README.md와 tools 폴더가 있습니다.

Git에 올리지 않은 파일, 로그인 정보, 실행 중인 AI와 로컬 대화는 함께 옮겨지지 않습니다. 이전 PC에서 필요한 작업기록이 저장·공유됐는지 확인하세요.

Step 2. PowerShell 7 준비하기

시작 메뉴에서 PowerShell 7을 찾습니다. 없으면 Windows 터미널에서 다음 명령으로 설치합니다.

winget install --id Microsoft.PowerShell --source winget

설치 후 새 터미널을 여세요. winget을 찾지 못하면 Microsoft 설치 안내에서 설치 파일을 사용합니다.

Step 3. Codex CLI 설치하기

공식 Codex CLI 설치 안내를 열고 Windows 항목의 절차를 따릅니다. 앱 내부의 버전별 폴더를 PATH에 직접 등록하는 방식보다 별도 CLI 설치를 권장합니다.

설치 후 새 PowerShell 창을 열어 확인합니다.

codex --version

확인: 버전이 나오면 준비 완료입니다. 찾을 수 없으면 설치 안내의 PATH 설정을 확인하세요.

Step 4. 프로젝트용 herdr 준비하기

탐색기로 project-management 폴더를 열고 주소창에 pwsh를 입력합니다.

Test-Path ./.local/bin/herdr/herdr.exe

True면 설치를 건너뜁니다. 새 PC에서 False면 아래 프로젝트 설치기를 실행합니다.

./tools/install_local_agents.ps1

이 설치기는 herdr 0.9.5와 Claude Code 2.1.308을 함께 프로젝트의 .local 폴더에 설치하고 파일을 검사합니다. 최신 버전 자동 설치기가 아니며 로그인은 하지 않습니다. Windows x64용이므로 ARM PC에서는 사용하지 말고 별도 설치 방법을 확인하세요.

확인: 두 도구의 ‘다운로드·설치 파일 검증 통과’가 표시됩니다. 오류가 있으면 다음 단계로 넘어가지 않습니다.

Step 5. 기존 PC 절차로 실행하기

1번의 Step 2부터 진행합니다. Codex의 첫 로그인에서는 본인 ChatGPT 계정을 선택합니다.

이전 PC의 바로가기와 고정 경로는 그대로 쓰지 않습니다. .local 도구는 Git에 포함되지 않으므로 PC별 준비가 필요합니다. Claude·Hermes의 로그인과 역할 연결은 이 시작 절차와 별도입니다.

3. 실행이 안 될 때

Step 1. 실행하지 않고 먼저 점검하기

프로젝트 폴더의 PowerShell 7에서 입력합니다. 현재 열린 AI는 건드리지 않습니다.

./tools/start_master.ps1 -CheckOnly

확인: 프로젝트·Codex 경로·버전·ChatGPT 로그인 상태가 표시됩니다. 문제가 있으면 오류 문구를 AI에게 전달하세요. 점검 통과는 실제 Codex 화면이 열렸다는 뜻은 아닙니다.

Step 2. 안내된 문제에 맞춰 처리하기

로그인 필요: 아래 명령으로 로그인한 뒤 Step 1을 다시 확인합니다.

./tools/start_master.ps1 -LoginCodex

설치 위치를 찾지 못함: Codex 설치를 확인합니다. 표준 설치 위치가 아닌 경우 확인한 실행 파일 경로를 지정할 수 있습니다.

./tools/start_master.ps1 -CodexPath "확인한 Codex 실행 파일 경로" -CheckOnly

점검 통과 후 같은 명령에서 -CheckOnly만 빼면 실행합니다. 로그인이나 서버 우회가 필요할 때도 같은 -CodexPath를 유지하고 -LoginCodex 또는 -NoDaemon을 붙이세요. 버전별 앱 경로를 Windows PATH에 매번 등록할 필요는 없습니다.

공유 서버 준비·연결 오류: 일반 실행이 실패했을 때만 아래 명령을 사용합니다.

./tools/start_master.ps1 -NoDaemon

-NoDaemon은 공유 서버 없이 실행하는 선택입니다. PATH 오류 해결 옵션은 아니며, 실패했다고 자동으로 이 방식으로 재실행하지 않습니다.

herdr 파일 없음 / 실행 차단 / 접근 거부: 프로젝트 위치와 PowerShell 7을 확인한 뒤 오류 문구를 AI에게 전달하세요. 관리자 실행이나 보안 설정 변경을 임의로 반복하지 않습니다.
