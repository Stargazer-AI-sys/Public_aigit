AI 작업 요청·진행·재개 사용자 가이드

여러 AI에게 직접 말하지 않고 마스터 GPT 한 곳에만 요청합니다. 준비 → 요청 → 진행 확인 → 재개 순서로 따라 하면 됩니다.

제한형 프로토타입입니다. 지금 확인된 것은 herdr·Claude 로컬 설치, Codex의 ChatGPT 로그인, Claude Pro 로그인입니다. Docker, Hermes, 자동 전달은 아직 연결되지 않았고, 사용자 창구 하나로 처음부터 끝까지 진행되는지도 아직 검증하지 않았습니다. 이 가이드의 대표 화면도 사용자 검토 전입니다.

모든 명령은 PowerShell 7에서 프로젝트 폴더(project-management)를 연 뒤 실행합니다. JSON 파일이나 상태 도구는 사용자가 다루지 않습니다. 마스터 GPT가 대신 관리합니다.

1. 준비 2. 요청 3. 진행 확인 4. 중단 후 재개

1. 준비

처음 한 번, 또는 새로 시작할 때 하는 일입니다. PowerShell 7에서 프로젝트 폴더를 연 뒤 시작 스크립트를 실행합니다.

./tools/start_master.ps1

herdr 화면이 열리면 그 안의 PowerShell에서 같은 명령을 한 번 더 실행합니다. 두 번째 실행에서 마스터 GPT가 시작됩니다.

./tools/start_master.ps1

확인: 첫 실행에서는 herdr가 열리고, herdr 안의 두 번째 실행에서는 마스터 GPT가 시작됩니다.

로그인 확인 문구나 설치 안내가 나오며 멈추면, 메시지를 그대로 마스터에게 알려 주세요. 이 프로토타입은 구독 로그인만 사용하며 API 키로 우회하지 않습니다.

2. 요청

마스터 GPT에게 평소 말투로 요청합니다. 대상, 목적, 원하는 범위, 확인 방법을 적으면 좋습니다.

문서 정리 가이드를 만들어줘.
대상은 나 혼자이고, 처음 한 번 준비와 매번 할 일을 구분해줘.
대표 한 페이지를 먼저 보여주고, 확인 뒤 제작·검토·시험 결과를 보고해줘.

확인: 마스터가 목적·대상·완료 기준을 정리해 알려 줍니다. 틀린 부분은 이때 바로잡으세요. 마스터가 대표 결과를 먼저 보여 주면 확인한 뒤 다음 진행을 말해 주세요.

3. 진행 확인

진행 중인 것과 검증된 완료를 구분해서 확인합니다. 마스터에게 이렇게 물어보세요.

지금 어느 단계야? 끝난 것과 아직 확인 못 한 것을 나눠서 알려줘.
보고 내용의미
진행 중작업이 아직 끝나지 않았습니다.
검토·시험 통과필수 결함이 없고 근거가 있습니다. 근거가 어디 있는지 마스터에게 물어볼 수 있습니다.
미검증·남은 제한아직 확인하지 못한 항목입니다. 완료로 취급하지 않습니다.

확인: “완료”라고만 하고 근거가 없으면 근거와 남은 제한을 함께 요청하세요. 제작과 별도로 검토와 시험이 있었는지도 물어볼 수 있습니다.

4. 중단 후 재개

작업이 멈췄거나 창을 닫았다면 1단계처럼 마스터를 다시 시작한 뒤 이어 가자고 요청합니다. 같은 작업을 처음부터 다시 시키지 마세요. 마스터가 기록된 마지막 완료 단계와 남은 일을 먼저 대조합니다.

이전 작업기록을 읽고 이어서 진행해줘.
마지막으로 끝난 단계와 남은 일을 먼저 알려주고, 이미 끝난 일은 반복하지 마.

확인: 마스터가 마지막 완료 단계와 남은 일을 먼저 알려 준 뒤에 이어서 진행합니다.

로그인 실패, 도구 미설치, 사용량 제한이 나오면 작업은 멈춘 상태로 기록됩니다. 해결한 뒤 위 재개 요청을 다시 보내세요.
