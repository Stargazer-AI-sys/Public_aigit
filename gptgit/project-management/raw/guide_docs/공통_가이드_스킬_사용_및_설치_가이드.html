스킬 호출은 Codex 채팅에, 복사·설치는 Windows PowerShell에 입력합니다. 아래 설치 명령은 기본 사용자 스킬 경로와 처음 설치하는 경우를 기준으로 합니다.

1. 스킬 사용 — Codex 채팅

공유 원본은 세 스킬 모두 gptgit/skills/에서 관리합니다. 현재 PC의 설치·목록 등록 여부는 각각 확인합니다. 프로젝트 규칙이 공유 원본 사용을 지정했다면 미설치 상태에서도 원본을 읽어 적용할 수 있습니다.

스킬사용하는 상황결과
simple-user-guide설치·실행·운영 방법을 짧게 안내할 때필수 절차·명령·확인 방법 중심의 HTML 가이드
project-planning아이디어·요구사항을 구체적인 기획으로 바꿀 때첫 버전 범위·사용 흐름·결과 예시·진행 순서·필수 질문
project-handoff프로젝트를 재개하거나 최신 인계를 점검할 때근거를 구분한 현재 상태·충돌·미확인 사항·다음 행동

Codex 채팅에 필요한 요청 하나를 입력합니다. 아래 프로젝트 경로와 작업명은 예시입니다.

$simple-user-guide로 [작업명] 가이드를 작성해줘. 필수 명령과 확인 방법만 간단하게 넣어줘.
$project-planning으로 이 요구사항을 구체화해줘. 핵심 기능과 대표 결과를 먼저 보여주고 중요한 결정만 질문해줘. 지금은 채팅으로만 제안해줘.
$project-handoff로 [대상 프로젝트 경로]의 최신 인계를 점검하고 현재 상태와 다음 작업을 알려줘. 파일 수정과 Git 작업은 하지 마.

확인: 요청에 맞는 스킬을 사용해 결과를 제공합니다. 기획·인계 스킬은 기본적으로 채팅으로 보고하며, 파일 반영·유료 호출·Git 작업은 별도 실행 조건을 따릅니다.

2. 공유 원본 확인

세 스킬의 Git 공유 원본 위치를 한곳으로 통합했습니다. 개인 설치본을 공유 원본 위에 다시 복사하지 않습니다.

스킬Aigit 기준 공유 폴더
simple-user-guidegptgit/skills/simple-user-guide
project-planninggptgit/skills/project-planning
project-handoffgptgit/skills/project-handoff

Aigit을 pull한 뒤 위 원본이 있는지 확인합니다. 원본이 없으면 경로·동기화 상태를 확인하고, 개인 설치본으로 임의 복구하지 않습니다. 공유 원본·개인 설치본은 서로 다른 역할입니다.

확인: 각 공유 폴더의 SKILL.md를 확인합니다. simple-user-guide에는 assets/guide-template.html도 필요합니다.

공유 원본을 새로 작성·수정한 PC에서는 사용자가 변경분을 확인해 commit·push합니다. 순서는 Git 가이드의 저장·전송을 따릅니다. 다른 PC에서 최신 원본을 pull로 받기만 했다면 이 단계는 필요하지 않습니다.

3. 다른 PC에 설치 — 처음 한 번

  1. 다른 PC에 Codex를 설치하고 로그인합니다.
  2. Aigit 저장소를 clone 또는 pull합니다. 위 공유 폴더가 내려왔는지 확인합니다.
  3. PowerShell을 Aigit 최상위 폴더에서 열고 설치할 스킬 하나씩 아래 절차를 사용합니다.

아래는 project-planning 예시입니다. 다른 두 스킬은 첫 줄의 이름만 project-handoff 또는 simple-user-guide로 바꿉니다. 개인 설치 위치는 이 PC에서 사용하는 경로를 확인한 뒤 설정합니다. 아래 .codex/skills는 기존 PC 구성 예시이며 모든 환경의 유일한 설치 위치는 아닙니다.

$skillName = "project-planning"
$skillSource = ".\gptgit\skills\$skillName"
$skillTarget = "$env:USERPROFILE\.codex\skills\$skillName"
if (-not (Test-Path -LiteralPath "$skillSource\SKILL.md")) { throw "공유 원본이 없습니다. 경로를 확인하세요." }
if (Test-Path -LiteralPath $skillTarget) { throw "이미 설치되어 있습니다. 기존 내용과 비교하세요." }
New-Item -ItemType Directory -Path "$env:USERPROFILE\.codex\skills" -Force
Copy-Item -LiteralPath $skillSource -Destination $skillTarget -Recurse

$skillName은 설치할 이름, $skillSource는 공유 원본, $skillTarget은 개인 설치 위치입니다. $env:USERPROFILE은 현재 Windows 사용자 폴더입니다. -LiteralPath는 정확한 원본 경로, -Destination은 설치 위치, -Recurse는 템플릿·참조 등 하위 파일도 복사한다는 뜻입니다.

설치 파일 확인:

Test-Path -LiteralPath "$skillTarget\SKILL.md"

simple-user-guide를 설치했다면 HTML 틀도 확인합니다.

Test-Path -LiteralPath "$skillTarget\assets\guide-template.html"

확인: 필요한 파일의 결과가 True인지 확인하고, Codex의 스킬 목록에 이름이 나타나는지 봅니다. 1번처럼 요청해 실제 사용도 확인합니다. 파일 존재만으로 등록·동작까지 확인한 것은 아닙니다. 목록이 갱신되지 않으면 새 채팅이나 앱 재실행 후 확인합니다.

설치 후에는 이 PC의 다른 로컬 프로젝트에서도 사용할 수 있습니다. 원격 스킬이 나중에 바뀌어도 개인 설치본은 pull만으로 자동 갱신되지 않습니다.
