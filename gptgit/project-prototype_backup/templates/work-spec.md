# 작업명세서 양식

> 양식이며 승인된 작업이 아니다. 사용자와 마스터가 내용을 확정한 뒤 해당 실행 원본으로 저장한다.

- 명세 ID·버전:
- 사용자 목표·사용 사례:
- 포함 범위 / 제외 범위:
- 요구사항 ID별 동작·입출력:
- 완료 조건과 검증 기준:
- 비용·구독·자료 전달·보류 조건:
- 허용 파일 변경 범위와 기록 대상·저장 시점:
- 사용자 결정이 필요한 조건:
- 승인 근거·일시:

기획 담당에게 전체 대화·과거 작업기록 대신 이 명세와 필요한 기술 근거만 전달한다. 미정은 미정으로 남기며 명세 작성이 실행 승인 자체를 뜻하지 않는다.
