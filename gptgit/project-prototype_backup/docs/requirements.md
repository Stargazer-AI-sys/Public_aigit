# 프로세스 적용 조건

> 버전 0.2 | 2026-11-04 | 프로젝트 자체 작업을 시작하기 위한 기준

이 문서는 특정 작업의 승인이나 완료 기록이 아니다. 실제 작업명세서는 [양식](../templates/work-spec.md)을 사용하여 사용자와 확정한다.

| 항목 | 실행 전 준비할 내용 | 확인 기준 |
| --- | --- | --- |
| 목표·범위 | 목적, 포함/제외, 요구사항 ID | 사용자가 명세와 실행 범위를 승인 |
| 완료 기준 | 요구사항별 예상 결과·시험 조건 | 실제 결과로 판정 가능 |
| 권한·비용 | 쓰기 대상, 기록 범위, 구독 경로, 중단 조건 | 마스터 위임 범위와 사용자 결정 구분 |
| 기획 검토 | 개발기획서, 검토할 고정 버전 | Claude 검토와 Codex 수정 후 마스터 판정 |
| 개발·QA | 담당 Task·소스, 별도 QA 세션 | 제작 자체 시험과 독립 실행 증거 구분 |
| 문서화 | 확정 변경·시험 근거·남은 제한 | 초안을 마스터가 대조하여 저장 |

자료나 연결이 없으면 해당 항목을 미정·미검증·차단으로 남긴다. 문서가 있다는 사실만으로 실행 승인·구현·검증을 완료로 취급하지 않는다. 실행 경계는 [AGENTS](../AGENTS.md)를 따른다.
